# Localization

- Only touch `localization/english/`. Other languages are generated by the user.
- **Localization documents the script.** Script says what the code does. `localization/english/` says what the player is told it does. This applies to every concept (decision, trait, modifier, event, interaction, story, religion, building, ...). To understand one, grep its identifier in `localization/english/` (english only) and read the entries before changing or explaining it.
- One identifier has sibling keys. For a decision: `<id>` (title), `<id>_desc` (in-world description), `<id>_tooltip` (hover text), `<id>_confirm` (confirm button). Never add a key without its siblings. When behaviour changes, update every sibling so the text stays true.
- File format: `.yml` is UTF-8 **with BOM**, with a trailing newline. Preserve line endings. Missing keys show raw in the UI and not at load time.
- Above hard-to-follow code, add a short comment taken from the loc text saying what it is for. Don't copy long descriptions.
