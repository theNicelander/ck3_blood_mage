# Blood Mage Religion Reference

This document outlines the technical architecture of the Cult of Quintessence religion subsystem in the Blood Mages mod.

## Religion Family and Structure

- **Religious Family**: `rf_quintessence` (`common/religion/religion_family_types/bm_religion_family.txt`).
- **Main Religion**: `quintessence_religion` (`common/religion/religion_types/bm_religion.txt`).
  - Family: `rf_quintessence`
  - Piety icon group: `quintessence_religion_piety_group`
  - Max holy sites: `holy_sites_max = 80`
  - Max eminent holy sites: `eminent_holy_sites_max = 3`
  - Virtues: `lifestyle_blood_mage`, `lifestyle_mystic`
  - Sins: `craven`, `content`
  - Carries the hidden identity doctrine `bm_quintessence_identity_doctrine`.

## The Seven Syncretic Faiths (`common/religion/faith_types/bm_faith_types.txt`)

Each faith is a root-level definition in `faith_types/` and carries a 1:1 mainline rite in `common/religion/rite_types/bm_rite_types.txt`:

1. **`quintessence_faith`** (Christian Syncretism):
   - Rite: `quintessence_rite`
   - Tenets: `tenet_christian_syncretism`, `tenet_esoteric`, `tenet_sacred_shadows`
2. **`quintessence_faith_islamic`** (Islamic Syncretism):
   - Rite: `quintessence_faith_islamic_rite`
   - Tenets: `tenet_islamic_syncretism`, `tenet_esoteric`, `tenet_sacred_shadows`
3. **`quintessence_faith_jewish`** (Jewish Syncretism):
   - Rite: `quintessence_faith_jewish_rite`
   - Tenets: `tenet_jewish_syncretism`, `tenet_esoteric`, `tenet_sacred_shadows`
4. **`quintessence_faith_eastern`** (Dharmic Syncretism):
   - Rite: `quintessence_faith_eastern_rite`
   - Tenets: `tenet_eastern_syncretism`, `tenet_esoteric`, `tenet_sacred_shadows`
5. **`quintessence_faith_sinitic`** (Sinitic Syncretism):
   - Rite: `quintessence_faith_sinitic_rite`
   - Tenets: `tenet_sinitic_syncretism`, `tenet_esoteric`, `tenet_sacred_shadows`
6. **`quintessence_faith_asatru`** (Norse Martial/Sacrifice):
   - Rite: `quintessence_faith_asatru_rite`
   - Tenets: `tenet_human_sacrifice`, `tenet_warmonger`, `tenet_esoteric`
7. **`quintessence_faith_unreformed`** (Pagan Traditionalist):
   - Rite: `quintessence_faith_unreformed_rite`
   - Tenets: `tenet_unreformed_syncretism`, `tenet_esoteric`, `tenet_sacred_shadows`

## Conversion Routing by Heritage

Located in `common/scripted_effects/bm_religion_conversion_effects.txt`:
- Scripted effect: `bm_convert_to_blood_cult_by_heritage_effect`.
- Inspects the convert's prior faith doctrines and syncretism:
  - Christian doctrine or syncretism -> `quintessence_faith`
  - Islamic doctrine or syncretism -> `quintessence_faith_islamic`
  - Jewish doctrine or syncretism -> `quintessence_faith_jewish`
  - Eastern doctrine or syncretism -> `quintessence_faith_eastern`
  - Sinitic doctrine or syncretism -> `quintessence_faith_sinitic`
  - Germanic/Norse religion tag -> `quintessence_faith_asatru`
  - Unreformed doctrine or syncretism -> `quintessence_faith_unreformed`
  - Fallback -> `quintessence_faith`

## Hidden Identity Doctrine and Compatibility

- Group: `bm_quintessence_identity_group` (`common/religion/doctrine_group_types/bm_doctrine_group_types.txt`)
- Doctrine: `bm_quintessence_identity_doctrine` (`common/religion/doctrine_types/bm_doctrine_types.txt`)
  - Parameters: `blood_magic_cult_faith`
- Compatibility trigger (`common/scripted_triggers/bm_religion_compatibility_triggers.txt`):
  ```txt
  bm_is_blood_cult_faith_trigger = {
      faith = {
          OR = {
              religion = { is_in_family = rf_quintessence }
              has_doctrine_parameter = blood_magic_cult_faith
          }
      }
  }
  ```
  Enables external companion mods (e.g. Vanilla Religions) or third-party faiths to opt into cult mechanics without hardcoded dependencies.

## Faith-Gated Initiation Requirements

Game rule: `bm_initiation_faith_requirement` (`common/game_rules/bm_game_rules.txt`):
- `bm_initiation_faith_requirement_cult`: Dedicated cult requirement (default).
- `bm_initiation_faith_requirement_witchcraft`: Cult or witchcraft accepted.
- Evaluated via `bm_meets_blood_mage_initiation_faith_requirement_trigger`:
  ```txt
  bm_meets_blood_mage_initiation_faith_requirement_trigger = {
      OR = {
          AND = {
              has_game_rule = bm_initiation_dedicated_cult
              bm_is_blood_cult_faith_trigger = yes
          }
          AND = {
              has_game_rule = bm_initiation_cult_or_witchcraft_accepted
              OR = {
                  bm_is_blood_cult_faith_trigger = yes
                  faith = { has_doctrine_parameter = witchcraft_accepted }
              }
          }
      }
  }
  ```

## Reformation Repair System

Unreformed Quintessence faiths are designed without a temporal head of faith.
- Decision: `bm_repair_quintessence_reformation_decision` (`common/decisions/bm_reformation_repair_decision.txt`)
- Trigger: `bm_can_repair_quintessence_reformation_trigger` (verifies human player, unreformed Quintessence faith, and self as head of faith)
- Effect: `bm_repair_quintessence_reformation_effect` (`remove_religious_head_title = yes`, replaces `doctrine_temporal_head` with `doctrine_no_head`)
- Console/Save Event fallback: `bm_reformation_repair.0001` (`events/bm_reformation_repair_events.txt`)
