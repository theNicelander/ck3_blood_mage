# v1.20.70: Devotion Prowess Scaling Floor & Trait Capstone Age Lock Polish

## Motivation

- Martial Blood Mages suffered a combat prowess regression upon elevating from Blood Acolyte to Blood Mage or Archmage.
  - While other attributes had their lower-tier 50 XP Devotion milestones absorbed into the higher-tier base trait floors (`diplomacy_per_piety_level`, `martial_per_piety_level`, etc.), `prowess_per_piety_level` was missing from the base stats of Mage and Archmage, causing characters with Bloodlust XP to drop in prowess when blank-slate elevation reset their tracks.
- Redundant track definitions cluttered higher-tier trait capstones.
  - All six 100 XP blocks on Mage and Archmage included `no_prowess_loss_from_age = yes` despite both base traits already providing the age prowess lock permanently.
- Blood Acolytes and Archmages were locked out of adopting the Blóðtrú faith.
  - The decision to embrace the faith (`become_blood_cultist_decision`) checked for the legacy `lifestyle_blood_mage` trait only, hiding and blocking conversion for newly initiated Blood Acolytes and ascended Archmages.
- Debug decision to add track XP was locked to Blood Mage only.
  - `debug_add_exp_blood_mage_exp` only targeted `lifestyle_blood_mage`, granting zero experience to characters holding `lifestyle_bm_acolyte` or `lifestyle_bm_archmage`. In addition, `debug_become_blood_mage` checked `not = { has_trait = lifestyle_blood_mage }`, leaving it visible when holding the Acolyte or Archmage traits.

## Changes

### Key changes

- Devotion Prowess Anti-Nerf Floors:
  - Added `prowess_per_piety_level = 1` to Tier II Blood Mage (`lifestyle_blood_mage`) base stats, matching the absorbed Tier I Bloodlust 50 XP milestone.
  - Added `prowess_per_piety_level = 2` to Tier III Blood Archmage (`lifestyle_bm_archmage`) base stats, matching the absorbed Tier II Bloodlust 50 XP milestone.
- Trait Capstone Age Lock Deduplication:
  - Removed `no_prowess_loss_from_age = yes` from all six 100 XP blocks (`bloodline`, `hematurgy`, `benediction`, `enlightenment`, `bloodlust`, `ancient`) on `lifestyle_blood_mage` and `lifestyle_bm_archmage`.
  - Retained `no_prowess_loss_from_age = yes` across all six 100 XP capstones on Tier I Blood Acolyte (`lifestyle_bm_acolyte`) as an impactful milestone unlock.
- Blóðtrú Faith Conversion for All Mage Tiers:
  - Updated `is_shown` and `is_valid` in `become_blood_cultist_decision` to check `is_blood_mage_any_tier_trigger = yes`, enabling Blood Acolytes, Blood Mages, and Blood Archmages to embrace the Blóðtrú faith.
- Unified Blood Mage Debug Track XP:
  - Updated `debug_add_exp_blood_mage_exp` in `common/decisions/bm_debug_decisions.txt` to award 20 XP across all 6 tracks (`ancient`, `enlightenment`, `bloodline`, `benediction`, `hematurgy`, `bloodlust`) to `lifestyle_bm_acolyte`, `lifestyle_blood_mage`, and `lifestyle_bm_archmage`.
  - Added fallback in `debug_add_exp_blood_mage_exp` to auto-initialize as a Blood Acolyte (`bm_become_blood_acolyte_effect = yes`) if no blood mage trait is held.
  - Updated `debug_become_blood_mage` visibility to `not = { is_blood_mage_any_tier_trigger = yes }`.
  - Updated English localization for `debug_add_exp_blood_mage_exp`.
- Blood Magic Situation Story UI Progression Integration:
  - Added `bm_sanguine_distillation_decision` ("Blood Distillation") and `bm_elevate_blood_mage_tier_decision` ("Ascend Blood Magic Tier") to the Situation Story decision list (`bm_blood_mage_story`).
  - Added dynamic tier icon branching in `bm_blood_mage_story` header (`bm_blood_bronze_burnished.dds` for Acolyte, `bm_blood_mage_silver.dds` for Mage, `bm_blood_archmage.dds` for Archmage).
  - Added `BM_BLOOD_MAGE_TIER_DISPLAY` customizable localization displaying active tier status in the situation header (`Tier: Blood Acolyte (Tier I)`, etc.).
  - Updated `bm_refresh_blood_magic_rosters_effect` to record knights and dynasty members of any blood mage tier (`is_blood_mage_any_tier_trigger`) in the retinue and dynasty rosters.
- Blood Distillation & Track XP Trigger Fix:
  - Fixed syntax error in `bm_has_track_xp_any_tier_trigger` in `common/scripted_triggers/bm_triggers.txt` where parameter markers were missing (`track = $`, `value >= $` -> `track = $TRACK$`, `value >= $VALUE$`).
  - Standardized all invocations of `bm_has_track_xp_any_tier_trigger` across `bm_sanguine_distillation_decision`, `bm_attune_lifeforce_decision`, `bm_elevate_tier_decision`, `bm_cull_champion_interaction`, `bm_men_at_arms_types`, and `bm_blood_mage_lifecycle_effects` to pass `VALUE = <number>` instead of invalid `VALUE >= <number>`.
  - Added macro parameter integrity validation in `scripts/check_repo.py` to detect unclosed `$` delimiters in game script files.
- Ascend Blood Magic Tier Requirements & Native Triggers Polish:
  - Added 250 Total Blood Magic track XP requirement (`bm_total_blood_mage_xp >= 250`) across all 6 lifestyle tracks to `bm_elevate_blood_mage_tier_decision`, retaining the 100 Ancient XP requirement.
  - Replaced redundant custom tooltips for Devotion, Runes, and Lifeforce with direct native CK3 triggers (`OR = { has_character_modifier = minor_blood_rune_modifier ... }` and `OR = { has_character_modifier = lifeforce_modifier_major ... }`), allowing the engine to display localized modifier requirement lists.
  - Allowed Blood Acolytes holding Superior Lifeforce to ascend, prioritizing consumption of Major Lifeforce if held.
  - Added progress tracker localization `bm_elevate_tier_total_xp_req` and cleaned up unused custom requirement keys.

### Other changes

- Synchronized `docs-ai/architecture/blood-mage-traits.md`, `docs-ai/architecture/blood-mage-decisions.md`, `docs-ai/architecture/blood-mage-religions.md`, and `docs-ai/architecture/blood-mage-story.md`.
