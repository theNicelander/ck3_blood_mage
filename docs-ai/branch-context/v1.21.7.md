# v1.21.7: Unify Duel Victory Lifeforce Rewards & Meet the Brokers UI
PR: #202

## Motivation
- Winning a Prisoner **Blood Pit Duel** (`bm_prisoner_blood_duel.0001`), a **Blood Hunt** duel (`seek_power.006`), or any lethal single combat kill (`bm_on_character_death_duel`) each used slightly different Lifeforce formulas.
  - Unifying them onto a single shared reward effect guarantees **+1 Major Lifeforce** plus the opponent's **Prowess%** chance for **+1 Superior Lifeforce** on every real single combat victory, while keeping **Blood Sparring Ring** Major-only.
- "Meet the Brokers" displayed a 10-line Requirements checklist even when all requirements were met, unlike Blood Hunt.
- **Major Exsanguination** (`bm_bleed_own_vein_interaction`) applied `lifedrained_modifier` on top of `wounded_2` and 25 Stress.
- **The Blood Rite** (`seek_power.011`) kept a ~4.2% failure floor even at maxed `prowess + learning`.

## Changes
### Key changes
- **The Blood Rite** (`seek_power.011`): Lowered `compare_modifier` `min` floors on `blood_escaped` (`-22` -> `-25`) and `blood_cursed` (`-13` -> `-15`) so high `prowess + learning` (`>= 41`) can reach `0%` fail chance.
- **Bleed Own Veins - Major Exsanguination** (`bm_bleed_own_vein_interaction`): Removed `lifedrained_modifier` from `major_bleed`; both `minor_bleed` (+1 wound tier) and `major_bleed` (+2 wound tiers: `none` -> `wounded_2`, `wounded_1` -> `wounded_3`) now require not `wounded_2`/`wounded_3`/`maimed` (`25` Stress unchanged).
- **Unified Duel Victory Lifeforce** (`bm_duel_victory_lifeforce_effect`, `bm_duel_superior_chance_value`): Added a shared scripted effect and opponent-scoped script value granting **+1 Major Lifeforce** plus an independent `opponent.prowess`% (`0–100%`) chance for **+1 Superior Lifeforce**.
  - **Prisoner Blood Pit Duel** (`bm_prisoner_blood_duel.0001`): Replaced the mutually exclusive Superior-or-Major roll with `bm_duel_victory_lifeforce_effect`.
  - **Lethal Single Combat Kills** (`bm_on_character_death_duel`): Replaced the hardcoded `+1 Major` + gated `25%` Superior roll with `bm_duel_victory_lifeforce_effect` inside the victory toast (no `20+` Prowess gate).
  - **Blood Hunt Duels** (`seek_power.006`): Replaced `+1 Major` + flat `25%` Superior with `bm_duel_victory_lifeforce_effect`.
  - **Blood Sparring Ring** (`bm_ritual_spar_events.0002`): Intentionally unchanged (**+1 Major Lifeforce** only, never Superior).
- **Meet the Brokers** (`bm_buy_captives_decision`): Switched from `is_valid` (`is_available_adult = yes`) to `is_valid_showing_failures_only` matching Blood Hunt's availability checks (`is_in_activity = no`, `is_travelling = no`, `is_imprisoned = no`, `is_incapable = no`) plus the existing `bm_buy_captives_cooldown` flag check.
- **Condense Lifeforce** (`bm_minor_condense`, `bm_major_condense`): Lowered Piety cost from `150` to `100` for Minor -> Major and from `350` to `250` for Major -> Superior (including `ai_chance` thresholds and localization tooltips).
