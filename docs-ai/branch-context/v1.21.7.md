# v1.21.7: Hide satisfied requirements on Meet the Brokers decision

## Motivation
- "Meet the Brokers" displayed a 10-line Requirements checklist even when all requirements were met, unlike Blood Hunt.

## Changes
### Key changes
- **Meet the Brokers** (`bm_buy_captives_decision`): Switched from `is_valid` (`is_available_adult = yes`) to `is_valid_showing_failures_only` matching Blood Hunt's availability checks (`is_in_activity = no`, `is_travelling = no`, `is_imprisoned = no`, `is_incapable = no`) plus the existing `bm_buy_captives_cooldown` flag check.
