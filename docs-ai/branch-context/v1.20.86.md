# v1.20.86 — Unify & Rename Tracks, Lifeforce Variants, and Dynasty Covenants

## Motivation
Unify naming and internal identifiers across all 6 Blood Mage lifestyle tracks, 6 specialized Lifeforce reservoirs, and 6 Dynasty House Covenants so every system shares one consistent vocabulary.

## Changes

### 1. Unified Track, Lifeforce & Covenant Mapping
- **Radiance** (`radiance`, `lifeforce_modifier_radiant` / **Radiant Blood**, `dynasty_blood_radiance_modifier_1..3` / **Covenant of Radiance**) ← replaces `benediction` / `lifeforce_modifier_presence` (Blood Presence) / `dynasty_blood_benediction_modifier_1..3`.
- **Cunning** (`cunning`, `lifeforce_modifier_cunning` / **Cunning Blood**, `dynasty_blood_cunning_modifier_1..3` / **Covenant of Cunning**) ← replaces `hematurgy` / `lifeforce_modifier_shadows` (Blood Shadows) / `dynasty_blood_hematurgy_modifier_1..3`.
- **Wisdom** (`wisdom`, `lifeforce_modifier_wise` / **Wise Blood**, `dynasty_blood_wisdom_modifier_1..3` / **Covenant of Wisdom**) ← replaces `enlightenment` / `lifeforce_modifier_focus` (Blood Focus) / `dynasty_blood_enlightenment_modifier_1..3`.
- **Fury** (`fury`, `lifeforce_modifier_furious` / **Furious Blood**, `dynasty_blood_fury_modifier_1..3` / **Covenant of Fury**) ← replaces `bloodlust` / `lifeforce_modifier_fury` (Blood Fury) / `dynasty_blood_bloodlust_modifier_1..3`.
- **Ancient** (`ancient`, `lifeforce_modifier_ancient` / **Ancient Blood**, `dynasty_blood_ancient_modifier_1..3` / **Covenant of the Ancient**) ← `lifeforce_modifier_ancient` replaces `lifeforce_modifier_mojo` (Blood Mojo); track & covenant IDs kept as `ancient`.
- **Fortune** (`fortune`, `lifeforce_modifier_fortunate` / **Fortunate Blood**, `dynasty_blood_fortune_modifier_1..3` / **Covenant of Fortune**) ← replaces `bloodline` / `lifeforce_modifier_prosperity` (Blood Prosperity) / `dynasty_blood_bloodline_modifier_1..3`.

### 2. Script, Assets, Localization & Docs
- Renamed trait tracks across `lifestyle_bm_acolyte`, `lifestyle_blood_mage`, and `lifestyle_bm_archmage` in `common/traits/bm_blood_mage_trait.txt`.
- Renamed track icons in `gfx/interface/icons/trait_level_tracks/` and covenant modifier icons in `gfx/interface/icons/modifiers/`, plus texticons in `gui/bm_blood_magic_texticons.gui`.
- Renamed story stack variables (`bm_lifeforce_{radiant,cunning,wise,furious,ancient,fortunate}_stacks`), XP script values (`bm_blood_mage_<track>_xp_value`), attunement modifiers (`<track>_attuned`), covenant custom loc (`BM_COVENANT_<TRACK>_*`), `add_xp_wisdom`, and `events/bm_channel_lifeforce_wisdom_minor_events.txt` (`namespace = bm_channel_lifeforce_wisdom_minor`).
- Updated all decisions, interactions, on-actions, scripted triggers/effects, events, English localization, and `docs-ai/architecture/` (including renaming `blood-mage-bloodlust.md` → `blood-mage-fury.md`).
- Unrelated `bloodline` feature names (`bm_empower_bloodline_decision`, `bm_bless_bloodline_interaction`) remain unchanged.
