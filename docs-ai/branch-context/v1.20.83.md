# v1.20.83: Fix Blood Mirror ascension duel tooltips, timing, and clone stats

## Motivation

- Hovering over **"Engage your reflection!"** in `bm_ascension_duel.0001` leaked internal setup effects under **Has Happened** (appearance copy, name change, and missing `force_character_skill_recalculation_global_past` loc) while showing `No immediate effects...` under **Will Happen**.
- In `bm_ascension_duel.0002`, tier elevation / defeat penalties and clone cleanup ran in `immediate` before the player clicked **"It is done."**, also showing `You gained Minor Lifeforce 0 times` when unspent XP overflow was `0`.
- The reflection's non-prowess stats were hardcoded to `20`, and prowess only matched the player instead of scaling by tier.

## Changes

### Key changes

- **Ascension Duel Start (`bm_ascension_duel.0001`)**:
  - Wrapped reflection creation and mirroring in `hidden_effect` and added `bm_ascension_duel.0001.opt.tt` so the option tooltip shows only that single combat begins.
- **Ascension Duel Conclusion (`bm_ascension_duel.0002` & `bm_elevate_tier_effect`)**:
  - Moved victory (`bm_elevate_tier_effect`) and defeat (`send_interface_toast`) effects from `immediate` into `option` so trait swap and penalties trigger on clicking **"It is done."**.
  - Moved reflection cleanup (`death_vanished`) into `after` (`hidden_effect`).
  - Guarded overflow Lifeforce in `bm_elevate_tier_effect` with `bm_elevation_overflow_lifeforce_stacks_value > 0` before `remove_trait` so `0`-stack overflow is omitted.
- **Reflection Stat Scaling (`bm_synchronize_character_skills_effect`)**:
  - Synced Diplomacy, Martial, Stewardship, Intrigue, and Learning to match the player's stats.
  - Scaled Prowess to player Prowess `+5` (Acolyte) or `+10` (Blood Mage -> Archmage).

### Other changes

- Synced `docs-ai/architecture/blood-mage-decisions.md` and `RELEASE_NOTES.md`.
