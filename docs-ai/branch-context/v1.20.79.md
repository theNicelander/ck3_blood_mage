# v1.20.79: Trait Appearance on All Tiers & Comprehensive 3-Tier Lifestyle Trait Rebalance

## Motivation

- Portrait alteration modifiers for hair and eyes were restricted to Tier II Blood Mage (`lifestyle_blood_mage`), ignoring Tier I Blood Acolyte (`lifestyle_bm_acolyte`) and Tier III Blood Archmage (`lifestyle_bm_archmage`). Characters starting as Acolytes or ascending to Archmages failed to render white hair or supernatural eyes regardless of the `bm_physical_alteration` game rule setting.
- Primary Blood Mage lifestyle tracks and base stat floors had disparate, uneven modifier numbers at 100 XP (e.g. +12% Army Damage, -12% Army Maintenance, +8 General Opinion, +0.20 Capital Dev Growth, +30% Devotion Impact, +1.00 Piety, +24% Piety Mult, +1.00 Renown, and +48.0 Life Expectancy on maxed Acolytes).
- Standardized all 10 core modifiers across the 3-tier hierarchy (Blood Acolyte / Blood Mage / Blood Archmage) at 100 XP with clean 5-milestone progression (10, 30, 50, 70, 100 XP) and anti-nerf base stat floors preserving 50 XP gains.

## Changes

### Key changes

- **Supernatural Portrait Appearance Across All Tiers**:
  - Added `lifestyle_bm_acolyte` and `lifestyle_bm_archmage` alongside `lifestyle_blood_mage` to `traits` filters across hair alteration (`bm_blood_mage_divine_hair_3` through `_5`) and eye alteration (`bm_blood_mage_divine_eyes_1` through `_5`).
  - Restored full appearance changes (white eyes and white hair) under game rule `On` (`bm_physical_alteration_on`) and progressive threshold scaling under game rule `Gradual` (`bm_physical_alteration_gradual`) across all three lifestyle tiers.
- **Comprehensive Lifestyle Trait & Track Rebalance (`common/traits/bm_blood_mage_trait.txt`)**:
  - **Army Damage (`bloodlust`)**: +15% (Acolyte, +3%/step) / +30% (Mage, +6%/step, +9% base floor) / +50% (Archmage, +10%/step, +27% base floor).
  - **Army Gold Maintenance (`bloodline`)**: -15% (Acolyte, -3%/step) / -30% (Mage, -6%/step, -9% base floor) / -50% (Archmage, -10%/step, -27% base floor).
  - **General Opinion (`benediction`)**: +10 (Acolyte, +2/step) / +20 (Mage, +4/step, +6 base floor) / +30 (Archmage, +6/step, +18 base floor).
  - **Knight Effectiveness per Learning (`enlightenment`)**: Completely purged from all 3 traits (base trait floors and tracks); sworn knight effectiveness per Prowess in `bloodlust` remains untouched.
  - **Capital County Development Growth (`bloodline`)**: +0.25/mo (Acolyte: +0.10 at 50, +0.15 at 100) / +0.50/mo (Mage: +0.20 at 50, +0.30 at 100, +0.10 base floor) / +1.00/mo (Archmage: +0.40 at 50, +0.60 at 100, +0.30 base floor).
  - **Devotion Impact (`ancient`)**: +25% (Acolyte: +10% at 50, +15% at 100) / +50% (Mage: +20% at 50, +30% at 100, +10% base floor) / +100% (Archmage: +40% at 50, +60% at 100, +30% base floor).
  - **Monthly Piety (flat) (`enlightenment`)**: +2.00/mo (Acolyte, +0.40/step) / +5.00/mo (Mage, +1.00/step, +1.20 base floor) / +10.00/mo (Archmage, +2.00/step, +4.20 base floor).
  - **Monthly Piety % (`enlightenment`)**: +30% (Acolyte, +6%/step) / +60% (Mage, +12%/step, +18% base floor) / +100% (Archmage, +20%/step, +54% base floor).
  - **Dynasty Renown (`ancient`)**: +1.00/mo (Acolyte, +0.20/step) / +2.00/mo (Mage, +0.40/step, +0.60 base floor) / +3.00/mo (Archmage, +0.60/step, +1.80 base floor).
  - **Life Expectancy**: Exactly +50.0 years (Acolyte: 24 vitality steps × 2.0 + 2.0 at Ancient 50) / +100.0 years (Mage: 24 vitality steps × 4.0 + 4.0 at Ancient 50, +26 base floor) / +200.0 years (Archmage: 24 vitality steps × 8.0 + 8.0 at Ancient 50, +78 base floor).
  - **Scheme Potential (`hematurgy`, `benediction`)**: +15% / -15% (Acolyte, +3%/-3% per step) / +30% / -30% (Mage, +6%/-6% per step, +9%/-9% base floor) / +50% / -50% (Archmage, +10%/-10% per step, +27%/-27% base floor).
