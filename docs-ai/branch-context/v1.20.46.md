# v1.20.46: Live Summary Document (Release Notes v1.15 -> v1.20) & Documentation Skill

## Summary & Motivation
Synthesizes all changes across 45+ version branches since the June 2025 baseline release (v1.15, git hash `0a94aa6372f037c9ea3729c2d7e93f729aea9d40`) into a public-facing, living release notes document (`RELEASE_NOTES.md`) structured specifically for players and Steam Workshop release announcements.   - Registered `RELEASE_NOTES.md` in repository layout and workflow checklists.

## Key Decisions
- **Net Diff Presentation**: Intermediate development steps (e.g., Crimson Warrior interaction → Crimson Knight trait → stepping stone to Blood Mage) are collapsed forward into their net final state (Blood Knight as a permanent Devotion-anchored martial peer to Blood Mage).
