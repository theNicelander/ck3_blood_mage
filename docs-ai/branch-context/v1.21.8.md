# v1.21.8: Lifeforce & Track Action Tables, Minor Rune XP Fix
PR: #203

## Motivation
- Provide quick-reference architecture tables of every Lifeforce-consuming action (grouped by Lifeforce tier) and every track-XP action (grouped by trait track).
- Align self-inscribed Blood Rune `ancient` XP to a clean `5 / 10 / 15` progression (`bm_minor_blood_rune` previously granted `6` instead of `5`).

## Changes
### Key changes
- **Inscribe Minor Blood Rune** (`bm_minor_blood_rune`): Lowered `ancient` XP from `6` to `5` so Minor / Major / Superior self-inscribed Blood Runes grant `5 / 10 / 15` `ancient` XP.
- **Lifeforce Actions Reference** (`docs-ai/architecture/blood-mage-lifeforce-actions.md`): Added per-tier tables (`superior lifeforce`, `major lifeforce`, `minor lifeforce`) with `Name`, `Piety Cost`, and `XP Gain` (multi-skill variants bundled).
- **Track Actions Reference** (`docs-ai/architecture/blood-mage-track-actions.md`): Added per-track tables (`wisdom`, `ancient`, `radiance`, `fortune`, `cunning`, `fury`) with `Name`, `Lifeforce Type + Piety Cost`, and `XP Gain`.

### Other changes
- Synced `docs-ai/architecture/blood-mage-blood-runes.md` self-inscription `ancient` XP to `+5 / +10 / +15`.
