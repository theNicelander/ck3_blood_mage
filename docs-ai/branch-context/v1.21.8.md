# v1.21.8: Action Tables, Cost & XP Rebalance, UI & Naming Cleanup
PR: #203

## Motivation
- Provide quick-reference architecture tables of every Lifeforce-consuming action (grouped by tier) and every track-XP action (grouped by trait track).
- Close the `Transmute Lifeforce` infinite XP loop and fix Piety, Lifeforce, and XP discrepancies surfaced by the audit.
- Trim redundant hover-text bloat in interaction and decision tooltips and align Covenant modifier IDs and file names.

## Changes
### Key changes
- **Transmute Lifeforce** (`bm_transmute_lifeforce.0002`): Removed XP grants from channeling Major Lifeforce into the 6 reservoir pools (pure passive-buff utility).
- **Condense & Split Lifeforce** (`bm_cast_blood_magic.txt`): Lowered `bm_cast_blood_magic_major_decision` top-level gate from `150` to `50` Piety and rebalanced option costs.
  - `bm_minor_condense`: `100` -> `50` Piety.
  - `bm_major_condense`: `250` -> `100` Piety.
  - `bm_superior_split`: `350` -> `100` Piety (`bm_major_split` unchanged at `50`).
- **Blood Runes** (`bm_minor_blood_rune`, `blessing_inscribe_rune`):
  - Set Minor Blood Rune Piety cost to `100` (matching tooltip and `100 / 200 / 400` scaling) for Self and Other.
  - Lowered `bm_minor_blood_rune` `ancient` XP from `6` to `5` (`5 / 10 / 15` self-inscription progression).
- **Carve Galdrastafir** (`bm_carve_galdrastafir_interaction`): Grants `+5 ancient` XP on first stave carved and `+5 wisdom` XP on stave swaps.
- **Ask for Blood Magic** (`ask_for_blood_magic_interaction`): Removed teacher `lifeforce_modifier_superior` requirement and consumption (costs only `250` Piety from the non-mage actor).
- **Empower Blood Mage** (`blessing_empower`): Removed `Empower Blood Mage` option from `bm_cast_blood_blessing_interaction`.
- **Childbirth XP** (`bm_on_birth_fortune_xp`): Moved birth XP from `fortune` to `ancient`.
  - Grants `+2` base or `+4` for inheriting Blood Mages (doubled to `+4 / +8` by Superior Feingur); removed old `+5 / +2` firstborn/subsequent split.
  - `+3 fortune` on Ancient Blood burn unchanged.
- **Other XP & Cost Fixes**:
  - **House Covenants** (`bm_upgrade_house_covenant_effect`): Grants `+3 / +5 / +8` XP in each covenant's matching track (`$COVENANT$`) instead of `fortune`.
  - **Initiate Blood Mage** (`grant_blood_magic_interaction`): Standardized to `+3 fortune` XP across all cases (Minor/Major, kin/non-kin).
  - **Embrace New Education** (`bm_education_new.001`): Bumped `wisdom` XP from `+6` to `+8`.
  - **Demand Blood Tithe** (`bm_tithe_lifedrain_success_effect`): Changed `+3` XP from `fortune` to `cunning`.
  - **Seek Captive Brokers** (`bm_purchase_broker_captive_effect`): Removed `+2 fortune` XP on purchase.
- **Tooltip & Hover-Text Cleanup**: Trimmed redundant effect/cost explanations across interactions, Covenant custom loc, and decision widgets.
