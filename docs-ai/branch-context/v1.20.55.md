# v1.20.55: Trait Variables Refactor, AI Lifedrain Court Protections & Engine Error Fixes

## Summary & Motivation
Refactor all fixed numerical modifier values across `lifestyle_blood_mage` and `lifestyle_blood_knight` trait tracks into reusable `@` script variables, standardize Blood Knight common stats, add a 1-year cooldown to Empower Dynasty Bloodline, protect spouses, children, knights, councillors, and court position holders from being lifedrained by AI blood mages, and resolve all mod errors in `error.log`.

## Core Concepts & Changes
- **AI Lifedrain Court Protections & Modifier Ordering Fix**:
  - `common/scripted_modifiers/bm_ai_value_modifiers.txt`: Inverted modifier evaluation order in `ai_willingness_to_lifedrain`. Additive modifiers (opinion multiplier, rival/nemesis bonuses, house penalties) are now placed at the top, while absolute `factor = 0` vetoes are placed at the bottom so no subsequent addition can resurrect a vetoed score back above zero. Fixed title-tier scoring so unlanded courtiers no longer gain an inadvertent +100 to +400 bonus.
  - Implemented total absolute AI vetoes (`factor = 0`) against lifedraining spouses/consorts, children, close family, knights/champions, councillors, employed court position holders (physicians, bodyguards, seneschal, caravan master), and Blood Golems, with no rival/nemesis bypass.
  - `common/character_interactions/bm_drain_lifeforce.txt` & `bm_drain_trait.txt`: Added engine-level hard validity gates (`trigger_if = { limit = { scope:actor = { is_ai = yes } } ... }`) in `is_valid_showing_failures_only` forbidding AI from selecting spouses, children, close family, knights, councillors, court positions, and blood golems. Human players retain complete roleplay agency.
- **Engine Error & Log Fixes**:
  - `common/traits/bm_blood_mage_trait.txt` & `bm_blood_knight_trait.txt`: Removed `good = yes` and `random_creation = 0.20`, eliminating all four `trait.cpp:405` and `trait.cpp:409` errors in `error.log`. Lifestyle traits are non-genetic and already handled through game rules and scripted birth on_actions.
  - `common/scripted_effects/bm_drain_all_prisoners_effects.txt`: Removed redundant internal `debug_log` in `lifedrain_execution_effect` to eliminate `pdx_data_localize.cpp:146` and `character.cpp:750` loc data errors when evaluating option tooltips during mass execution events.
  - `.agents/rules/ck3-scripting.md`: Documented engine errors 8 (`Trait flags on non-genetic traits`) and 9 (`Clausewitz ai_will_do modifier ordering & factor = 0 score resurrections`) in the Living Catalog.
- **Reusable Trait Track Script Variables**:
  - `common/traits/bm_blood_mage_trait.txt`: Defined 42 reusable script variables categorized by track comments (`# General stats`, `# bloodline`, `# hematurgy`, `# benediction`, `# enlightenment`, `# ancient`). All tier blocks now reference these `@bm_*` variables.
  - `common/traits/bm_blood_knight_trait.txt`: Defined 32 reusable script variables categorized by track comments (`# General stats`, `# vanguard`, `# slaughter`, `# benediction`, `# enlightenment`, `# ancient`). All tier blocks now reference these `@bm_*` variables.
- **Blood Knight Common Stat Standardization**:
  - Replaced legacy `@bm_mage_common_*` references in Blood Knight's `benediction`, `enlightenment`, and `ancient` tracks with `@bm_common_*` (`health = 0.1`, `life_expectancy = 2`, `years_of_fertility = 1`, `epidemic_resistance = 1`), establishing full stat parity.
- **Empower Dynasty Bloodline Decision Cooldown (`bm_empower_bloodline_decision`)**:
  - Added native `cooldown = { years = 1 }` to `bm_empower_bloodline_decision.txt` to prevent rapid spamming.
  - Updated architecture docs (`blood-mage-decisions.md`, `blood-mage-dynasty.md`, `blood-mage-magic-tiers.md`, `blood-mage-track-xp.md`) and `RELEASE_NOTES.md` to document the 1-year cooldown.
- **Trait Description Tuning**:
  - Updated trait descriptions in `localization/english/bm_traits_l_english.yml` for concise, evocative phrasing.

## Key Decisions
- **AI-Only Restriction**: Enforced through `scope:actor = { is_ai = yes }` blocks in interaction validity and AI weights, leaving player agency unrestricted.
- **Total Ban on Spouses & Kids**: Blocked unconditionally even in prison or as rivals/nemeses for AI characters.
- **Factor = 0 Ordering**: Positioned all vetoes at the very end of `ai_will_do` calculations in accordance with Clausewitz engine evaluation rules.
- **Self-Contained File Variables**: Defined variables at the top of both trait files independently so that each trait definition remains modular, self-contained, and easily readable without cross-file script value lookups.
- **1-Year Decision-Level Cooldown**: Standardized to native CK3 decision `cooldown = { years = 1 }`, ensuring clear UI cooldown display without requiring custom flag tracking.
