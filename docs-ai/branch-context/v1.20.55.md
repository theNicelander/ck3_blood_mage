# v1.20.55: Blood Mage Track Restructuring (Part 1), Trait Variables, AI Lifedrain Protections, Ritual Sparring Decision & Engine Fixes

## Summary & Motivation
Restructure the `bloodline` and `hematurgy` tracks in `lifestyle_blood_mage` to match the clean 10-step cadence of `lifestyle_blood_knight`, eliminating UI bloat by capping unique modifiers at 3–5 items and preventing CK3 decimal truncation bugs via whole-integer constraints. Refactor fixed numerical modifier values across `lifestyle_blood_mage` and `lifestyle_blood_knight` trait tracks into reusable `@` script variables, standardize Blood Knight common stats, add a 1-year cooldown to Empower Dynasty Bloodline, protect spouses, children, knights, councillors, and court position holders from being lifedrained by AI blood mages, convert the ritual sparring character interaction into an annual courtyard decision (`bm_ritual_spar_decision`) with prowess-weighted candidate selection and practice Single Combat Engine (SCE) bouts, and resolve all mod errors in `error.log`.

## Core Concepts & Changes

  - `common/decisions/cast_magic/bm_ritual_spar_decision.txt`: Created yearly blood magic decision costing 1 Minor Lifeforce stack, requiring at least one living, adult sworn knight who possesses `lifestyle_blood_knight`.
  - Sequentially samples up to 3 distinct candidates without replacement using native `random_knight` with `weight = { base = 0 modifier = { add = prowess min = 1 } }`, guaranteeing candidate selection probability is proportional to their prowess ($w_i = \text{prowess}_i$).
  - `events/bm_ritual_spar_events.txt`: Created `bm_ritual_spar_events.0001` (3 candidate sparring options + refund cancellation) initiating non-lethal Single Combat Engine bouts (`FATALITY = practice`, `LOCALE = courtyard`).

  - Implemented invalidation event `bm_ritual_spar_events.0003` to clean shirtlessness and refund Minor Lifeforce if bout aborts.

## Key Decisions
- **Prowess-Proportional Sampling Without Replacement**: Chose sequential `random_knight` calls with `weight = { base = 0 modifier = { add = prowess min = 1 } }` and exclusions (`NOT = { this = scope:spar_partner_X }`), mirroring vanilla while satisfying the exact mathematical requirement $P(i) = \text{prowess}_i / \sum \text{prowess}_k$.
- **Practice Fatality (`FATALITY = practice`)**: Guaranteed non-lethal, wound-free sparring where knights cannot be permanently crippled or killed in the ring.
- **Major Lifeforce Prize**: Elevated the sparring stakes so the victor condenses 1 Major Lifeforce stack from the intense combat expenditure, with both participants gaining Blademaster trait XP.
- **Standardized Cadence Alignment**: Aligned Blood Mage's `bloodline` and `hematurgy` tracks with Blood Knight's 10-step model to ensure consistent UI density and progression pacing across both classes.
- **Whole-Integer / Clean Multipliers**: Used whole percentages like `0.03` domain tax and `0.10` inactive inheritance to prevent decimal truncation and floating precision issues in CK3 UI formatting.
- **AI-Only Restriction**: Enforced through `scope:actor = { is_ai = yes }` blocks in interaction validity and AI weights, leaving player agency unrestricted.
- **Total Ban on Spouses & Kids**: Blocked unconditionally even in prison or as rivals/nemeses for AI characters.
- **Factor = 0 Ordering**: Positioned all vetoes at the very end of `ai_will_do` calculations in accordance with Clausewitz engine evaluation rules.
- **Self-Contained File Variables**: Defined variables at the top of both trait files independently so that each trait definition remains modular, self-contained, and easily readable without cross-file script value lookups.
- **1-Year Decision-Level Cooldown**: Standardized to native CK3 decision `cooldown = { years = 1 }`, ensuring clear UI cooldown display without requiring custom flag tracking.
