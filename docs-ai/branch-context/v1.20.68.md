# v1.20.68: Blood Knight Consolidation into Blood Mage Bloodlust Track

## Motivation

- Simplify the lifestyle progression system by replacing the parallel `lifestyle_blood_knight` trait with a unified, 6-track `lifestyle_blood_mage` trait.
- Consolidate military and prowess progression into a single martial track (`bloodlust`), merging battlefield victory and single-combat/tournament XP gain into one streamlined progression.
- Lay the structural foundation for a future linear progression (Acolyte → Mage → Archmage) without parallel competing classes.

## Changes

### Key changes

- **Unified Lifestyle Trait (`lifestyle_blood_mage`):**
  - Added 6th lifestyle track: `bloodlust`, dedicated to martial, prowess, advantage, knight limit, and dread.
  - Granted `ignores_gender_army_rules` ("Worthy Commander") to all Blood Mages.
  - Fully removed `lifestyle_blood_knight` trait definition, game rule `bm_blood_knight_prevalence`, and prevalence review pulses.
- **Merged Martial Progression (`bloodlust`):**
  - Integrated battlefield victory/defeat XP and single combat fatal duel/tournament XP into `bloodlust` with rebalanced half-rate values (+1 to +3 battle victory, +1 defeat, +3 fatal duel, +2 tournament completion).
  - Merged Blood Hunt martial rewards into `bloodlust`.
- **Interactions & Decisions Cleanup:**
  - Removed `make_blood_knight_interaction` and `empower_blood_knight_interaction`.
  - Expanded `empower_blood_mage_interaction` to grant `bloodlust` XP alongside `bloodline` and `enlightenment`.
  - Removed class transmutation options and effects from Cast Superior Blood Magic.
  - Consolidated sacred geyser duel (`bm_geyser_duel.0001`) into a single Learning and Prowess trial bestowing `lifestyle_blood_mage`.
- **Men-at-Arms & Buildings:**
  - Recruitable Blood Berserkers and Blood-Bound Behemoths now check `has_trait = lifestyle_blood_mage` gated by devotion levels.
  - Duchy and domicile buildings updated to reference `lifestyle_blood_mage`.

### Other changes

- **Documentation & Archive:**
  - Created `docs-ai/archive/blood-knight-removed.md` preserving reference documentation.
  - Updated all live subsystem architecture docs to reflect the unified 6-track Blood Mage structure.
