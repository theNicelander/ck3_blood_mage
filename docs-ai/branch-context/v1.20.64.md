# v1.20.64: Add Playable Icelandic Culture with Equal Martial Custom

## Motivation

- Iceland lacked a distinct culture at game start (867 and 1066), defaulting to Norse and Norwegian, with Icelandic only existing as a dynamic hybrid/divergent naming entry.
- Players wishing to start with or customize an Icelandic character required manual divergence or custom mod setup.

## Changes

### Key changes

- Update Current Situation healing alert (`bm_action_can_heal`):
  - Expand candidate collection to include court position holders (`every_court_position_holder`) and close family members (`every_close_family_member`) alongside self, spouses, children, lovers/soulmates, friends/best friends, liege, councillors, and knights.
  - Introduce dynamic green vs gray visual feedback mirroring vanilla declare war:
    - Added scripted triggers `bm_actor_can_heal_target_ailments_trigger` and `bm_actor_has_lifeforce_to_heal_target_trigger` evaluating whether the actor can cure the target's afflictions (respecting Blood Knight limits on deadly ailments) and holds the matching Lifeforce tier.
    - Added `unimportant` condition to `bm_action_can_heal` in `common/important_actions/bm_important_actions.txt`, dynamically styling the notification button green (`Status_Suggestion_Good`) when Lifeforce is available, and neutral gray (`Status_Suggestion`) when Lifeforce is lacking.
    - Added customizable localization `bm_heal_lifeforce_status_current_situation` in `common/customizable_localization/bm_heal_custom_loc.txt` providing colored status tags `#P @health_icon! Can Heal#!` (green) and `#low @health_icon! Needs Lifeforce#!` (gray) on action labels.
    - Added sibling localization keys `bm_action_can_heal_unimportant` and `bm_action_can_heal_combined_unimportant` displaying warning tooltips when lacking Lifeforce.
    - Updated `bm_is_valid_positive_magic_target_trigger` in `common/scripted_triggers/bm_triggers.txt` to include `employer ?= $ACTOR$` for court positions.
- Add playable `bm_icelandic` culture available at game start and in the Ruler Designer under North Germanic heritage.
  - Retains Norwegian baseline ethos (`ethos_bellicose`), language (`language_norse`), and North Germanic heritage (`heritage_north_germanic`).
  - Sets `martial_custom = martial_custom_equal`, allowing both men and women to serve as commanders and knights.
  - Features 5 cultural traditions: Coastal Warriors (`tradition_fp1_coastal_warriors` with fallback `tradition_hird`), Maritime Mercantilism (`tradition_maritime_mercantilism`), Dexterous Fishermen (`tradition_fishermen`), Ting-Meet (`tradition_things`), and Northern Stories (`tradition_fp1_northern_stories` with fallback `tradition_runestones`).
  - Implements dedicated Icelandic name list (`bm_name_list_icelandic`) with full Icelandic saga representation, modern/saga epenthetic `-ur` endings (e.g. Ingólfur, Ólafur, Sigurður, Haraldur, Guðmundur), user-specified names (Pétur, Natan, Salka, Arnfinnur, Lára, Sara, Þorarna, Kolbeinn, Konráð, Þórhallur, Þorvarður, Þorsteinn, Anna, Klara, Orri, Sverrir, Eggert, Ragnar, Sindri, Kristján, Einar, Guðfinnur, Sigrún), historical clan dynasties (`dynn_Oddaverjar`, `dynn_Sturlung`, `dynn_SvI_nfelling`, `dynn_A_sbrning`, `dynn_HaukdA_lir`), and patronymics (`-sson` / `-sdottir`).
  - Populates North Germanic baseline historical innovations for 867, 950, and 1066 start dates.
  - Adds modular `on_game_start` setup in `bm_setup_icelandic_culture_on_start` converting de jure counties of `d_iceland` and all resident rulers, courtiers, family members, and barony holders to `bm_icelandic` on Day 1 without overwriting vanilla history files.
  - Adds game rule `bm_icelandic_culture` (`bm_icelandic_culture_enabled` [default] vs `bm_icelandic_culture_disabled`) allowing players to toggle the Day 1 conversion of Iceland on or off.
