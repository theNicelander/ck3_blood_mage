# v1.20.64: Add Playable Icelandic Culture with Equal Martial Custom

## Motivation

- Iceland lacked a distinct culture at game start (867 and 1066), defaulting to Norse and Norwegian, with Icelandic only existing as a dynamic hybrid/divergent naming entry.
- Players wishing to start with or customize an Icelandic character required manual divergence or custom mod setup.

## Changes

### Key changes

- Add playable `bm_icelandic` culture available at game start and in the Ruler Designer under North Germanic heritage.
  - Retains Norwegian baseline ethos (`ethos_bellicose`), language (`language_norse`), and North Germanic heritage (`heritage_north_germanic`).
  - Sets `martial_custom = martial_custom_equal`, allowing both men and women to serve as commanders and knights.
  - Features 5 cultural traditions: Northern Stories (`tradition_fp1_northern_stories` with fallback `tradition_runestones`), Ting-Meet (`tradition_things`), Performative Honor (`tradition_fp1_performative_honour` with fallback `tradition_poetry`), Dexterous Fishermen (`tradition_fishermen`), and Hird (`tradition_hird`).
  - Implements dedicated Icelandic name list (`bm_name_list_icelandic`) with historical saga names, historical clan dynasties (`dynn_Oddaverjar`, `dynn_Sturlung`, `dynn_SvI_nfelling`, `dynn_A_sbrning`, `dynn_HaukdA_lir`), and patronymics (`-sson` / `-sdottir`).
  - Populates North Germanic baseline historical innovations for 867, 950, and 1066 start dates.
  - Adds modular `on_game_start` setup in `bm_setup_icelandic_culture_on_start` converting de jure counties of `d_iceland` and their local rulers/courts to `bm_icelandic` on Day 1 without overwriting vanilla history files.
