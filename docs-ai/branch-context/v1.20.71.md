# v1.20.71: Blood Mirror Ascension Duel Player Mirror Opponent & Native Toast Polish

## Motivation

- In the Blood Magic tier elevation ritual (`bm_elevate_blood_mage_tier_decision` -> `bm_ascension_duel.0001`), the opponent was a generic template character with a random culture name, hardcoded Lowborn dynasty, fixed personality (`brave` and `wrathful`), no education, and arbitrary base stats (except for prowess).
- To realize the ritual's narrative fantasy of overcoming one's own reflection in single combat, the opponent must be an exact mirror of the player character in name, appearance, dynasty presentation, personality, education, physical traits, and all 6 core attributes.
- Ascension duel defeat toast obscured mechanical impact behind a generic custom tooltip.
  - Players losing the ascension combat received an interface toast with static text rather than standard engine formatting for injuries, exhaustion, and Ancient track XP deduction.

## Changes

### Key changes

- **Ghost Dynasty Architecture**:
  - Dynamically branches reflection creation in `bm_ascension_duel.0001`: if player has a house/dynasty, spawns with `dynasty = generate`, then sets house name to `bm_ghost_house_name` (`"Ghost [root.GetHouse.GetBaseNameNoTooltip]"`, e.g. "Arthur of Ghost Pendragon").
  - If player is Lowborn, reflection spawns with `dynasty = none`.
  - Avoids polluting the player's dynasty tree and family line upon reflection death/vanishing.
- **Name & Appearance Mirroring**:
  - Dynamically copies player's given name (`change_first_name = { template_character = root }`) and appearance (`copy_inheritable_appearance_from = root`).
- **Template Neutralization**:
  - Set `bm_blood_reflection_template` attributes to 0 (`diplomacy = 0`, `martial = 0`, `stewardship = 0`, `intrigue = 0`, `learning = 0`, `prowess = 0`), removed hardcoded `brave`/`wrathful`/`prowess = 10`.
- **Modular Mirroring Scripted Effects** (`common/scripted_effects/bm_ascension_duel_effects.txt`):
  - `bm_copy_character_personality_effect`: Mirrors all 36 standard vanilla personality traits from player to reflection.
  - `bm_copy_character_education_effect`: Mirrors diplomacy, martial, stewardship, intrigue, learning (tiers 1-5), and prowess education (tiers 1-4).
  - `bm_copy_character_mirror_traits_effect`: Mirrors congenital/physical traits (beauty, intellect, physique, giant, dwarf, albino, strong, shrewd, fecund, pure_blooded, physical defects), combat lifestyle traits (blademaster, hunter, berserker, viking, varangian), and active blood mage tier (`lifestyle_bm_acolyte`, `lifestyle_blood_mage`, `lifestyle_bm_archmage`).
  - `bm_synchronize_character_skills_effect`: Dynamically computes the delta for all 6 attributes (`diplomacy`, `martial`, `stewardship`, `intrigue`, `learning`, `prowess`) and applies `add_<skill>_skill`, recalculating skills for identical final stats.
- **Ascension Duel Defeat Native Toast**:
  - Moved modifier (`bm_casting_exhaustion_modifier`), injury trait (`wounded_1` / `wounded_2`), and Ancient track experience penalty (-10 XP) inside `send_interface_toast` in `bm_ascension_duel.0002`.
  - Removed redundant `custom_tooltip` (`bm_ascension_duel_loser_tt`), allowing the CK3 engine to format the consequences natively with icons, traits, and track XP diffs.
- **Starting Holders Game Rule Fix**:
  - Updated `bm_initialize_starting_counties_and_holders_effect` in `common/scripted_effects/bm_starting_counties_effects.txt` so landed rulers in Iceland and Tsushima start with the Tier 2 Blood Mage trait (`lifestyle_blood_mage`) via `bm_become_blood_mage_tier_2_effect` rather than the Acolyte trait (`lifestyle_bm_acolyte`).
- **Engine Script & Database Error Log Hygiene**:
  - Fixed unset event target `scope:blessing_blood` in `bm_blood_blessing.txt` AI evaluation, updating to `scope:blessing_bless_blood` and eliminating over 2,700 runtime error reports.
  - Replaced unsupported `set_temporary_variable` and `change_temporary_variable` calls in `bm_blood_mage_lifecycle_effects.txt` with standard `set_variable` and `change_variable` followed by clean variable purging.
  - Replaced invalid `random = { ... } else = { ... }` blocks in `bm_blood_mage_prevalence_on_actions.txt` with standard `random_list`.
  - Restored missing `add_blood_power_xp` macro alias (+10 XP) in `bm_trait_track_xp_gain_effects.txt` for `events/bm_blood_power_event.txt`.
  - Renamed legacy `temporary_buff_self` modifier to `bm_empower_versatility_modifier` across `bm_modifiers.txt`, `bm_blood_power_event.txt`, and `bm_modifiers_l_english.yml`.
  - Deduplicated 85 Icelandic character and dynasty names in `bm_icelandic_l_english.yml` and 2 holy site names in `bm_xuedao_l_english.yml` that collided with vanilla definitions.
  - Removed duplicate `bm_casting_exhaustion_modifier` keys from `bm_decisions_l_english.yml`.
  - Simplified 45 decision `debug_log` statements removing runtime `Select_CString(root.IsPlayer)` data localization errors.
- **English Localization**:
  - Added `bm_ghost_house_name` in `localization/english/event_localization/bm_ascension_duel_events_l_english.yml`.
- **Universal XP Progression & Decision Availability**:
  - Replaced hardcoded `add_trait_xp = { trait = lifestyle_blood_mage ... }` in `bm_self_rites.txt` (hematurgy), `bm_blood_drain.txt` (hematurgy, bloodline), and `bm_curse_blood.txt` (hematurgy trigger) with `bm_add_blood_mage_xp_effect` and `bm_has_track_xp_any_tier_trigger`, allowing Tier 1 Acolytes and Tier 3 Archmages to progress track XP and reach tier ascension thresholds.
  - Updated decision visibility (`is_shown`) in `bm_ritual_spar_decision.txt`, `bm_mass_lifedrain_prisoners.txt`, `bm_seek_power_decision.txt`, and `bm_manifest_lifeforce.txt` from `has_trait = lifestyle_blood_mage` to `is_blood_mage_any_tier_trigger = yes`.
  - Added piety and Lifeforce requirement checks (`piety >= 150`, `piety_level >= 1`, Lifeforce modifier present) to `bm_empower_bloodline_decision.txt` to prevent AI rulers from spamming covenant upgrades and incurring massive negative piety debt.
  - Standardized decision `debug_log` data-factory promote syntax across all decision files from `[root.GetShortUINameNoTooltip] (ID:[root.GetID])` to `[ROOT.Char.GetShortUINameNoTooltip] (ID:[ROOT.Char.GetID])`.
