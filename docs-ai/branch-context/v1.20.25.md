# v1.20.25

## Summary & Motivation

Branch `v1.20.25` adds the Major Blood Magic channel ritual to manifest, level up, or cleanse congenital trait branches (`intellect`, `physique`, `beauty`), with support for ranks up to 5 for modded environments:
- Initiated as an option in the "Cast Major Blood Magic" event (`bm_cast_blood_magic_major.001`), routing to `bm_channel_manifest_traits.001`.
- Implements a self-learning duel (`duel = { skill = learning ... }`) where higher learning, learning traits, and Blood Mage XP aid success.
- Implements strict 1-step progression (`-3 -> -2 -> -1 -> neutral -> +1 -> +2 -> +3 -> +4 -> +5` with `max = 5`).
- Trait draining (`events/bm_trait_drain_events.txt` and `bm_can_drain_traits_from_target_trigger`) updated to support draining up to rank 5.
- Difficulty scales inversely with trait tier: flaws are easiest to improve, while reaching apex congenital traits faces severe difficulty additions.
- Existing positive traits increase failure weight, making further genetic perfection increasingly difficult.
- Tiered risk: standard failure consumes Major Lifeforce with major exhaustion; critical failure inflicts wounds and stress.
- Piety costs scale from 200 Piety (curing worst flaw) up to 1050 Piety (manifesting tier 5).

## Core Concepts & Changes

- **Major Ritual Hub Integration**:
  - `bm_cast_blood_magic_major.001`: Added option `bm_cast_blood_magic_major.001.manifest_traits` launching `bm_channel_manifest_traits.001`.
- **Manifestation Event & Options**:
  - `bm_channel_manifest_traits.001`: Offers Intellect, Physique, Beauty, and a Cancel/reconsider option, gated with `has_trait_rank < 5`.
- **Trait Drain Integration**:
  - `events/bm_trait_drain_events.txt` and `common/scripted_triggers/bm_trait_triggers.txt`: Gates lifted from hardcoded rank 3 to `rank < 5` via `has_trait_rank`.
  - `common/script_values/bm_drain_duel_values.txt`: Added rank 4 and rank 5 weight evaluations.
- **Script Values**:
  - `common/script_values/bm_manifest_traits_values.txt`: Scaled Piety costs (up to 1050 for rank 5), Learning trait bonuses, Blood Mage XP bonus, existing traits penalty, and per-branch tier modifiers up to rank 5.
- **Scripted Effects**:
  - `common/scripted_effects/bm_manifest_traits_effects.txt`: Deterministic 1-step ladder upgrade (`bm_manifest_upgrade_trait_step_effect` with `max = 5`) and per-branch self learning duels (`bm_manifest_intellect_duel_effect`, `bm_manifest_physique_duel_effect`, `bm_manifest_beauty_duel_effect`).
- **Localization**:
  - `localization/english/bm_channel_manifest_traits_l_english.yml`: Keys for ritual, branches, duel outcomes, and toast notifications.

## Key Decisions

- **Access Point**: Embedded into `bm_cast_blood_magic_major.001` rather than standalone decision to keep all major rites centralized.
- **Self-Duel Stat**: Learning skill chosen as the uniform arcane stat, boosted by specific scholastic/mystic traits.
- **Ladder Progression & Compatibility**: Uses `change_trait_rank` with `max = 5` and `has_trait_rank` triggers so games with mods adding congenital ranks 4 and 5 seamlessly level up to rank 5, while vanilla environments cap naturally at rank 3.
