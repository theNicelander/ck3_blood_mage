# v1.20-5

## Summary & Motivation

This branch completes the migration of the Blood Mages mod's religion architecture to match CK3 1.20 vanilla standards. Following the major base-game update to religions and faiths, this overhaul resolves layout incompatibilities, introduces mainline rites, updates holy site modifier mechanics, separates faith definitions into `faith_types/`, and cements the new architecture in developer rules and system documentation.

## Core Concepts & High-Level Changes

- **Faith Separation into `faith_types/`**: Extracted all 7 Quintessence faiths (`quintessence_faith`, `quintessence_faith_islamic`, `quintessence_faith_jewish`, `quintessence_faith_eastern`, `quintessence_faith_sinitic`, `quintessence_faith_asatru`, `quintessence_faith_unreformed`) from `religion_types/bm_religion.txt` into root-level definitions in `common/religion/faith_types/bm_faith_types.txt`. Updated each faith to use `faith_details = { ... }`, explicit `tenets = { ... }`, and `doctrines = { ... }`.
- **Mainline Rites in `rite_types/`**: Introduced `common/religion/rite_types/bm_rite_types.txt` defining a 1:1 mainline rite for each faith. This ensures each faith has a stable, localized ritual identity and prevents the engine from generating untracked dynamic rites (`dynamic_rite_%i`).
- **Holy Site Modifier Overhaul**: Converted all 43 custom holy sites in `common/religion/holy_site_types/bm_holy_sites.txt` from the legacy `character_modifier = { ... }` block to the dual 1.20 format: `county_holder_character_modifier = { ... }` (county holder if same faith) and `faith_character_modifier = { ... }` (global faith bonus when Eminent).
- **Holy Site Allocation**: Assigned 3 Eminent Holy Sites (Iceland's `talknafjordur` and `reykjavik`, plus a signature thematic site) and 6 Regular Holy Sites to each syncretic variant, while preserving all 43 custom holy sites for reformation, divergence, and conversion.
- **Religion Family Tenet Banners**: Updated `bm_religion_family.txt` to replace obsolete `doctrine_background_icon` with the four 1.20 background banners (`tenet_background_icon`, `tenet_heretical_background_icon`, `tenet_neutral_background_icon`, `tenet_unknown_background_icon`).
- **Doctrine & Group Schema Corrections**: Linked `bm_quintessence_identity_doctrine` to its group via mandatory `doctrine_group_type = bm_quintessence_identity_group`, removed the obsolete `doctrine_types` container from `bm_doctrine_group_types.txt`, and formatted the parameter flag as `parameters = { blood_magic_cult_faith }`.
- **Rules & Documentation**: Updated `.agents/rules/ck3-religions.md` and `AGENTS.md` with complete 1.20 guidelines, and created `docs-ai/architecture/blood-mage-religions.md`.

## Key Decisions

- **We decided to create 1:1 mainline rites for every faith** because CK3 1.20 generates anonymous dynamic rites with missing localization unless an explicit mainline rite is scripted.
- **We decided to curate 3 Eminent and 6 Regular holy sites per faith** because CK3 1.20 sets a default cap of 9 holy sites and Eminent sites now grant global bonuses; assigning 61 holy sites to every faith causes UI overflow and unintended global modifier stacking.
- **We decided to retain all 43 custom holy site definitions in `bm_holy_sites.txt`** with modernized modifiers so that any player or dynamic rite reforming or creating a custom faith has access to the full suite of mod holy sites.
- **We decided to preserve exact database keys across faiths, rites, and doctrines** so existing conversion scripted effects (`bm_religion_conversion_effects.txt`), triggers, and localization entries require zero breaking changes.
