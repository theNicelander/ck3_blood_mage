# v1.20.62: Standardize Event Exit Options to "Back" & Update AI Guidelines

## Motivation

- Multi-stage spell menus, diagnostics, and ritual events used inconsistent, verbose flavour text on cancellation and back-out options.
  - Options like "Step back and abandon the ritual", "Decide against healing for now", or "Abort the ritual" caused visual clutter and inconsistency across dialogue menus.

## Changes

### Key changes

- Standardize all ritual, healing, and spell event cancellation and back-out options to concise `"Back"`.
  - Replaces verbose flavour text across `bm_heal_ailment`, `bm_heal_old_age`, `bm_reshape_personality`, `bm_channel_manifest_traits`, and `bm_bestow_traits`.

### Other changes

- Update AI guidelines in `AGENTS.md`, `.agents/rules/ck3-localization.md`, and `.agents/rules/ck3-events.md` establishing `"Back"` as the strict project standard for all menu navigation and exit options.
