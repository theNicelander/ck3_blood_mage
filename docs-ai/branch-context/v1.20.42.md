# v1.20.42: Attune to Trait Track Widget UI, Guaranteed Yearly XP & Skill Documentation

## Summary & Motivation

Modernizes discipline Attunement in the Blood Mage mod:
1. Replaces the event popup modal (`bm_attune_lifeforce.001`) inside Minor Blood Magic (`bm_cast_blood_magic_minor.001`) with a standalone decision `bm_attune_lifeforce_decision` (`common/decisions/cast_magic/bm_attune_lifeforce_decision.txt`) utilizing CK3 1.20's inline multi-choice option-list widget (`decision_view_widget_generic_multichoice_with_effects` and `decision_option_list_controller`). Each track button displays its `45x45` DDS track icon (`gfx/interface/icons/trait_level_tracks/<track>.dds`), localized hover description, and dynamic live effect previews.
2. Converts the yearly discipline Attunement XP pulse from a 50% random roll into a **guaranteed 100% (+1 XP)** gain every year during `random_yearly_everyone_pulse` (`blood_mage_yearly_events.001` for Blood Mages and `.004` for Blood Knights).
3. Updates the Superior **Hulinhjálmur** (*Unseen Shroud*) Galdrastafir capstone to **double guaranteed yearly Attunement XP from +1 XP to +2 XP per year**.
4. Adds developer agent skill `.agents/skills/add-decision-option-widget/SKILL.md` documenting how to author inline multi-choice option-list widget decisions in CK3 1.20.

## Core Concepts & Changes

- **Standalone Option-List Widget Decision (`bm_attune_lifeforce_decision`)**:
  - Visible in Realm Decisions list under `bm_decision_group` and registered in the Blood Magic Situation panel (`common/story_cycles/bm_blood_mage_story.txt`).
  - Gated at `has_character_modifier = lifeforce_modifier_minor` and `piety >= 25`. Costs 25 Piety and consumes 1 Minor Lifeforce, updating Lifeforce counters via `bm_recount_lifeforce_stacks_effect = yes`.
  - Filtered items by character archetype:
    - Shared: Ancient (`bm_attune_ancient`), Enlightenment (`bm_attune_enlightenment`), Benediction (`bm_attune_benediction`).
    - Blood Mage: Bloodline (`bm_attune_bloodline`), Hematurgy (`bm_attune_hematurgy`).
    - Blood Knight: Vanguard (`bm_attune_vanguard`), Slaughter (`bm_attune_slaughter`).
  - Currently active attunement is greyed out (`is_valid = { NOT = { has_character_modifier = <track>_attuned } }`).
  - Evaluates dynamic effect blocks dynamically in UI preview when clicking options.
- **Guaranteed Yearly Discipline Attunement XP**:
  - Removed `random = { chance = 50 ... }` wrappers in `blood_mage_yearly_events.001` (Mages) and `blood_mage_yearly_events.004` (Knights).
  - Fires reliably on a random day once per year, awarding `+1` XP in the attuned track (`+2` XP when `bm_rune_hulinhjalmur_superior` is held).
- **Superior Hulinhjálmur Capstone Update**:
  - Doubles yearly Attunement discipline XP gain to `#P +2 XP#!` per year in `events/bm_yearly_events.txt`.
  - Updated descriptions in `bm_modifiers_l_english.yml`, `bm_blood_runes_l_english.yml`, and `bm_blood_mage_story_l_english.yml`.
- **Event File Cleanup**:
  - Removed `bm_cast_blood_magic_minor.001.attune` from `events/bm_cast_blood_magic_minor_events.txt`.
  - Deleted unused event file `events/bm_attune_lifeforce_events.txt` per `.agents/rules/ck3-events.md`.
- **New Skill (`add-decision-option-widget`)**:
  - Added `.agents/skills/add-decision-option-widget/SKILL.md`. Linked in `.agents/skills/add-blood-magic-decision/SKILL.md` and `AGENTS.md`.

## Key Decisions & Trade-Offs

- **Decision Widget vs Event Modal**: Moved track selection out of `bm_cast_blood_magic_minor.001` into a dedicated standalone decision using `decision_view_widget_generic_multichoice_with_effects`. Eliminates nested event popups and surfaces available disciplines alongside their track icons directly in the Situation and Realm Decisions list.
- **Guaranteed +1 XP vs 50% Roll**: Replaced RNG dice rolls with guaranteed +1 XP per year. Since Attunement requires active commitment (1 Minor Lifeforce + 25 Piety) and character slot exclusivity (only one attunement allowed at a time), guaranteed yearly progression provides predictable progression while Superior Hulinhjálmur serves as a major acceleration multiplier (+2 XP/yr).
- **Script Value `ai_chance` Warning**: Documented critical CK3 engine trap where `ai_chance` inside `decision_option_list_controller` items evaluates strictly as a script value (`value = N`, `if = { limit = { ... } add = M }`), not an event weight block (`base = N`, `modifier = { ... }`).
