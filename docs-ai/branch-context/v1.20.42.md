# v1.20.42: Attune to Trait Track Widget UI, Guaranteed Yearly XP & Skill Documentation

## Summary & Motivation

Modernizes discipline Attunement in the Blood Mage mod:
1. Replaces the event popup modal (`bm_attune_lifeforce.001`) inside Minor Blood Magic (`bm_cast_blood_magic_minor.001`) with a standalone decision `bm_attune_lifeforce_decision` (`common/decisions/cast_magic/bm_attune_lifeforce_decision.txt`) modeled directly after vanilla's **"Invite Religious Exiles"** (`invite_religious_exiles_decision` using `decision_view_widget_option_list_generic` with `show_from_start = yes` and `decision_option_list_controller`). Options appear immediately inside the decision view under "Select a valid option", with 45x45 track icons, localized failure tooltips, and a confirm button.
2. Converts the yearly discipline Attunement XP pulse from a 50% random roll into a **guaranteed 100% (+1 XP)** gain every year during `random_yearly_everyone_pulse` (`blood_mage_yearly_events.001` for Blood Mages and `.004` for Blood Knights).
3. Updates the Superior **Hulinhjálmur** (*Unseen Shroud*) Galdrastafir capstone to **double guaranteed yearly Attunement XP from +1 XP to +2 XP per year**.
4. Adds developer agent skill `.agents/skills/add-decision-option-widget/SKILL.md` documenting how to author inline multi-choice option-list widget decisions in CK3 1.20.

## Core Concepts & Changes

- **Standalone Option-List Widget Decision (`bm_attune_lifeforce_decision`)**:
  - Visible in Realm Decisions list under `bm_decision_group` and registered in the Blood Magic Situation panel (`common/story_cycles/bm_blood_mage_story.txt`).
  - Gated at `has_character_modifier = lifeforce_modifier_minor` and `piety >= 25`. Costs 25 Piety and consumes 1 Minor Lifeforce, updating Lifeforce counters via `bm_recount_lifeforce_stacks_effect = yes`.
  - Filtered items by character archetype:
    - Shared: Ancient (`bm_attune_ancient`), Enlightenment (`bm_attune_enlightenment`), Benediction (`bm_attune_benediction`).
    - Blood Mage: Bloodline (`bm_attune_bloodline`), Hematurgy (`bm_attune_hematurgy`).
    - Blood Knight: Vanguard (`bm_attune_vanguard`), Slaughter (`bm_attune_slaughter`).
  - Currently active attunement is greyed out (`is_valid = { NOT = { has_character_modifier = <track>_attuned } }`).
  - Evaluates dynamic effect blocks dynamically in UI preview when clicking options.
- **Guaranteed Yearly Discipline Attunement XP**:
  - Removed `random = { chance = 50 ... }` wrappers in `blood_mage_yearly_events.001` (Mages) and `blood_mage_yearly_events.004` (Knights).
  - Fires reliably on a random day once per year, awarding `+1` XP in the attuned track (`+2` XP when `bm_rune_hulinhjalmur_superior` is held).
- **Superior Hulinhjálmur Capstone Update**:
  - Doubles yearly Attunement discipline XP gain to `#P +2 XP#!` per year in `events/bm_yearly_events.txt`.
  - Updated descriptions in `bm_modifiers_l_english.yml`, `bm_blood_runes_l_english.yml`, and `bm_blood_mage_story_l_english.yml`.
- **Event File Cleanup**:
  - Removed `bm_cast_blood_magic_minor.001.attune` from `events/bm_cast_blood_magic_minor_events.txt`.
  - Deleted unused event file `events/bm_attune_lifeforce_events.txt` per `.agents/rules/ck3-events.md`.
- **New Skill (`add-decision-option-widget`)**:
  - Added `.agents/skills/add-decision-option-widget/SKILL.md`. Linked in `.agents/skills/add-blood-magic-decision/SKILL.md` and `AGENTS.md`.
- **Interaction Requirement Tooltip Localization Fixes**:
  - Added missing `NOT_` companion keys for `bm_manifest_lifeforce_requirement_tt`, `bm_manifest_lifeforce_cooldown_tt`, `bm_heal_ailment_resource_requirement_tt`, `bm_recipient_already_blessed`, `bm_inscribe_rune_other_requirement_tt`, `bm_recipient_already_feingur_blessed`, and `bm_enhance_blood_ritual_location_requirement_tt`. Resolves CK3 engine missing loc bug when `is_valid_showing_failures_only` conditions evaluate to false.

- **Manifest Lifeforce Offering Tiers Rebalance (`bm_manifest_lifeforce_interaction`)**:
  - Rebalanced offering tiers per design specification:
    - **Tier 1 (100 Piety)**: `+3` Enlightenment XP. Chance to succeed (Major ~14%, Minor ~41%), chance to fail with nothing (~32%), and critical failure inflicts **Major recoil exhaustion** (`temporary_negative_lifeforce_effect_major = yes`, ~14%).
    - **Tier 2 (250 Piety)**: `+5` Enlightenment XP. Chance to succeed (Major ~27%, Minor ~45%), chance to fail with nothing (~18%), and critical failure inflicts **Minor recoil exhaustion** (`temporary_negative_lifeforce_effect_minor = yes`, ~9%).
    - **Tier 3 (500 Piety)**: `+8` Enlightenment XP. **Guaranteed Minor Lifeforce upfront** (outside duel options). Learning duel options: good chance of 1 Major Lifeforce (~70%), small chance of 2x Major Lifeforce (~15%), small chance of no additional gain (~15%). Cannot fail / zero recoil risk.
    - **Tier 4 (1000 Piety)**: `+12` Enlightenment XP. **Guaranteed Minor Lifeforce AND 1x Major Lifeforce upfront** (outside duel options). Learning duel options: good chance of 2x Major Lifeforce (~80%), small chance of Superior Lifeforce (~20%). Zero failure risk.
  - Added outcome toast localization keys `manifest_lifeforce_double_major_success_tt`, `manifest_lifeforce_minor_failure_penalty_tt`, and `manifest_lifeforce_nothing_extra_tt`.

## Key Decisions & Trade-Offs

- **Decision Widget vs Event Modal**: Moved track selection out of `bm_cast_blood_magic_minor.001` into a dedicated standalone decision modeled directly on vanilla's `invite_religious_exiles_decision` (`decision_view_widget_option_list_generic` with `show_from_start = yes`). Options are displayed immediately inside the decision view under "Select a valid option", with track icons, localized failure tooltips, and a confirm button, eliminating nested event popups.
- **Guaranteed +1 XP vs 50% Roll**: Replaced RNG dice rolls with guaranteed +1 XP per year. Since Attunement requires active commitment (1 Minor Lifeforce + 25 Piety) and character slot exclusivity (only one attunement allowed at a time), guaranteed yearly progression provides predictable progression while Superior Hulinhjálmur serves as a major acceleration multiplier (+2 XP/yr).
- **Script Value `ai_chance` Warning**: Documented critical CK3 engine trap where `ai_chance` inside `decision_option_list_controller` items evaluates strictly as a script value (`value = N`, `if = { limit = { ... } add = M }`), not an event weight block (`base = N`, `modifier = { ... }`).
- **Guaranteed Upfront Floors in Manifest Lifeforce**: Implemented guaranteed Minor Lifeforce at 500 Piety and guaranteed Minor + Major at 1000 Piety by placing `add_character_modifier` directly in `on_accept` before the `duel` block. In CK3's interaction preview window, this clearly distinguishes unconditional baseline gains from the conditional duel rolls (such as 2x Major or Superior).
