# v1.20.42: Attune to Trait Track Widget UI, Guaranteed Yearly XP & Skill Documentation

## Summary & Motivation

Modernizes discipline Attunement in the Blood Mage mod:
1. Replaces the event popup modal (`bm_attune_lifeforce.001`) inside Minor Blood Magic (`bm_cast_blood_magic_minor.001`) with a standalone decision `bm_attune_lifeforce_decision` (`common/decisions/cast_magic/bm_attune_lifeforce_decision.txt`) modeled directly after vanilla's **"Invite Religious Exiles"** (`invite_religious_exiles_decision` using `decision_view_widget_option_list_generic` with `show_from_start = yes` and `decision_option_list_controller`). Options appear immediately inside the decision view under "Select a valid option", with 45x45 track icons, localized failure tooltips, and a confirm button.
2. Converts the yearly discipline Attunement XP pulse from a 50% random roll into a **guaranteed 100% (+1 XP)** gain every year during `random_yearly_everyone_pulse` (`blood_mage_yearly_events.001` for Blood Mages and `.004` for Blood Knights).
3. Updates the Superior **Hulinhjálmur** (*Unseen Shroud*) Galdrastafir capstone to **double guaranteed yearly Attunement XP from +1 XP to +2 XP per year**.
4. Adds developer agent skill `.agents/skills/add-decision-option-widget/SKILL.md` documenting how to author inline multi-choice option-list widget decisions in CK3 1.20.

## Key Decisions & Trade-Offs

- **Blood Golem Piety Rank 4 Requirement**: Forging an immortal Blood Golem construct from clay and Superior Lifeforce represents an apex rite of hematurgy; gating it at Piety Rank 4 (Paragon of Virtue / Devoted Servant) aligns construct synthesis with high devotion tier capabilities in line with other Superior rites.
- **Clean Milestones vs Mixed Stacking**: Removed repetitive small stat increments (like +0.1 prestige, +2% movement speed, +1 prowess) from tiers 50 and 100. This makes milestone achievements in CK3 feel distinctly transformative and impactful, while redistributing the values across standard tiers so that characters still achieve full power when progressing through a track.
- **Decision Widget vs Event Modal**: Moved track selection out of `bm_cast_blood_magic_minor.001` into a dedicated standalone decision modeled directly on vanilla's `invite_religious_exiles_decision` (`decision_view_widget_option_list_generic` with `show_from_start = yes`). Options are displayed immediately inside the decision view under "Select a valid option", with track icons, localized failure tooltips, and a confirm button, eliminating nested event popups.
- **Guaranteed +1 XP vs 50% Roll**: Replaced RNG dice rolls with guaranteed +1 XP per year. Since Attunement requires active commitment (1 Minor Lifeforce + 25 Piety) and character slot exclusivity (only one attunement allowed at a time), guaranteed yearly progression provides predictable progression while Superior Hulinhjálmur serves as a major acceleration multiplier (+2 XP/yr).
- **Script Value `ai_chance` Warning**: Documented critical CK3 engine trap where `ai_chance` inside `decision_option_list_controller` items evaluates strictly as a script value (`value = N`, `if = { limit = { ... } add = M }`), not an event weight block (`base = N`, `modifier = { ... }`).
- **Guaranteed Upfront Floors in Manifest Lifeforce**: Implemented guaranteed Minor Lifeforce at 500 Piety and guaranteed Minor + Major at 1000 Piety by placing `add_character_modifier` directly in `on_accept` before the `duel` block. In CK3's interaction preview window, this clearly distinguishes unconditional baseline gains from the conditional duel rolls (such as 2x Major or Superior).
- **Single Combat `FATALITY = possible` with `seek_power.006` Resolution**: Using `FATALITY = possible` prevents instant game-over deaths on a bad round while still inflicting real combat wounds; handling the lifeforce harvest and recruitment choice in `OUTPUT_EVENT` (`seek_power.006`) ensures victorious Blood Knights reliably get their Major + 25% Superior Lifeforce reward even when `FATALITY = possible` leaves the opponent wounded rather than dead.
