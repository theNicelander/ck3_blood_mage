# v1.20.30 - Egill Geyser Initiation: Blood Knight & Blood Mage Dual Duel

## Summary & Motivation
Expands the initiation trial at the geysers of Reykjavik (Vestisland) and Tsushima (`bm_geyser_duel.0001`) so that players can become a Blood Knight (`lifestyle_blood_knight`) through a Prowess duel against Egill Skallagrímsson, in parallel to becoming a Blood Mage (`lifestyle_blood_mage`) through a Learning duel.

## Core Concepts & Changes
- **Egill Dual Mastery**: Egill Skallagrímsson spawns with both `lifestyle_blood_mage` and `lifestyle_blood_knight`.
- **Single Decision Gateway**: Both `bm_blood_cultist_become_blood_mage_decision` and `bm_enhance_blood_ritual_decision` are shown to characters missing either `lifestyle_blood_mage` OR `lifestyle_blood_knight`.
- **Gating Requirements**: Taking the trial requires either Devotion Level >= 2 (`piety_level >= 2`) OR Fame Level >= 2 (`prestige_level >= 2`), along with geographic presence in Reykjavik (`c_vestisland`) or Tsushima (`c_tsushima`).
- **In-Event Duel Choice & Level Cost**:
  - Both options are always visible in the event window (`show_as_unavailable = { always = yes }`), grayed out if the character does not meet the minimum requirements or already has the trait.
  - **Learning Duel (Blood Mage)**: Requires `piety_level >= 2`. On first attempt, deducts 1 Devotion level (`add_piety_level = -1`). Single-tick Learning duel against Egill; success awards `lifestyle_blood_mage`.
  - **Prowess Duel (Blood Knight)**: Requires `prestige_level >= 2`. On first attempt, deducts 1 Fame level (`add_prestige_level = -1`). Single-tick Prowess duel against Egill; success awards `lifestyle_blood_knight`.
  - **Back Out**: Leaves Egill undisturbed with zero piety/prestige cost.
- **Failures & Retries**: Defeats inflict trauma/injuries and allow retrying the duel. Flags (`bm_geyser_paid_piety` and `bm_geyser_paid_prestige`) track paid entry so retrying a duel does not charge additional piety/prestige levels.

## Key Decisions
- **Decision Cost**: Decision is free upfront; the level cost is incurred upon choosing which path to contest in the event.
- **Show as Unavailable**: Using `show_as_unavailable = { always = yes }` ensures both paths are visible to the player at all times, with informative engine tooltips detailing requirements when locked.
