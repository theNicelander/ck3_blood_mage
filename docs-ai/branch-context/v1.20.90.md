# v1.20.90: Interaction Modals, Minor Life Drain Rework & UX Unification

## Motivation

- Casting permanent Blood Blessings previously split the UX across a standalone decision (`bm_self_blessing_decision`) and a nested option inside `bm_blood_blessing_interaction` that opened an intermediate event (`bm_blood_blessing.001`).
- **Empower Dynasty Bloodline**, **Carve Galdrastafir**, **Blood Distillation**, and **Attune Lifeforce** used inline decision widgets or intermediate events instead of the unified `open_interaction_window` modal pattern, and decision-level cooldowns could be burned on cancel.
- **Minor Life Drain** (`drain_minor`) left a permanent `recently_lifedrained_modifier` / `lifeforce_modifier_negative_minor` instead of a per-victim 3-month cooldown with escalating wound severity.

## Changes

### Key changes

- **Dedicated `Cast Blood Blessing` Interaction (`bm_cast_blood_blessing_interaction`)**:
  - Created `common/character_interactions/bm_cast_blood_blessing.txt` with `send_options_exclusive = yes` and the 6 permanent Blood Blessing lines (**Radiance**, **Fortune**, **Fury**, **Cunning**, **Wisdom**, **Ancient**) directly as radio `send_option`s in the interaction modal.
  - Evaluates dynamic Piety cost (`50`/`150`/`250`) via `cost = { piety = ... }` (removed duplicate `add_piety` calls from `bm_apply_blessing_effect`) and targets self, children, dynasty kin, spouses/consorts, knights, councillors, or liege.
  - Removed `blessing_bless_blood` from `bm_blood_blessing_interaction` and deleted `events/bm_blood_blessing_events.txt`.
- **Minor Blood Magic Grimoire (`bm_cast_blood_magic_minor_decision`)**:
  - Removed `common/decisions/cast_magic/bm_self_blessing_decision.txt`.
  - Added **Cast Blood Blessing** (`bm_minor_blood_blessing`) inside `bm_cast_blood_magic_minor_decision`, opening `bm_cast_blood_blessing_interaction` on `root` via `open_interaction_window`.
- **Empower Dynasty Bloodline (`bm_empower_bloodline_decision` -> `bm_empower_bloodline_interaction`)**:
  - Replaced the inline widget in `bm_empower_bloodline_decision` with `open_interaction_window` for `bm_empower_bloodline_interaction` (`hidden = yes`, `send_options_exclusive = yes`, 7 Covenant `send_option`s).
  - Moved Piety deduction (`150`/`350`/`750`) into `bm_empower_bloodline_interaction`'s `cost` block (removed duplicate `add_piety` from `bm_empower_bloodline_effects.txt`) and moved the 1-year cooldown (`bm_empower_bloodline_cooldown`) into `on_accept` so canceling the popup does not consume the cooldown.

- **Minor Life Drain (`bm_blood_drain_interaction`: `drain_minor`)**:
  - Replaced `recently_lifedrained_modifier` (`years = 1`), `lifeforce_modifier_negative_minor`, and the actor-wide 3-month cooldown with a 3-month per-victim cooldown (`bm_minor_lifedrain_cooldown` on `scope:recipient`).
  - Inflicts escalating wounds on `scope:recipient` via `increase_wounds_effect = { REASON = lifedrain_reason }` (`wounded_1` -> `wounded_2` -> `wounded_3` -> death).
- **UX Unification & Polish**:
  - Added **Cast Blood Blessing** (`bm_major_blood_blessing`, `bm_superior_blood_blessing`) shortcuts to Major and Superior Grimoires (`bm_cast_blood_magic.txt`), so self-casting works from whichever Grimoire matches current Lifeforce.
  - Converted `bm_carve_galdrastafir_decision`, `bm_blood_distillation_decision`, and `bm_minor_attune` (`bm_attune_lifeforce_events.txt` removed) to `hidden = yes`, `send_options_exclusive = yes` interaction modals (`bm_carve_galdrastafir_interaction`, `bm_blood_distillation_interaction`, `bm_attune_lifeforce_interaction`) launched via `open_interaction_window`.
  - Fixed `bm_empower_bloodline_interaction` `current_description` keys (`bm_covenant_*_tooltip`) and cascading `starts_enabled` via `bm_can_upgrade_covenant_trigger` so the first affordable Covenant starts pre-selected.
  - Fixed `bm_blood_drain_interaction` `starts_enabled` cooldown/modifier guards on `drain_minor`, `drain_stored`, and `drain_tithe`.
  - Removed `this = scope:actor` from `bm_blood_blessing_interaction` `is_shown` (eliminating an empty self-menu), removed deprecated `blessing_consecrate_union`, and fixed the `"Anoint Heir"` typo.
  - Updated all 18 `bm_blessing_*` modifiers to use matching `bm_covenant_*` skill icons and aligned `@bm_blessing_xp_add_superior` to `15` (matching loc/docs).
