# v1.20.85: Remove Blood Power, expand Transmute Lifeforce to 6 reservoirs, and add Ancient Lifestyle XP

## Motivation

- Replace the secondary `lifestyle_blood_power` trait and its `quarterly_playable_pulse` payout with 6 specialized Transmute Lifeforce reservoirs using native `monthly_*_lifestyle_xp_gain_add` modifiers, eliminating trait tooltip bloat and quarterly pulse overhead.
- Give the Ancient track and Mage/Archmage promotion floors a progression-focused Lifestyle XP bonus and add Situation reminders for Attune Lifeforce and Prisoner Trait Drain.

## Changes

### Key changes

- **Remove `lifestyle_blood_power`**: Deleted `common/traits/bm_blood_power_trait.txt`, `events/bm_blood_power_event.txt`, `common/script_values/bm_blood_power_values.txt`, `common/script_values/bm_channel_values.txt`, and `gfx/interface/icons/trait_level_tracks/{dynasty,warband,mastery,presence,prosperity,shadows}.dds`. Removed the `bm_major_channel_power` Major Grimoire option, `quarterly_playable_pulse` (`blood_mage_yearly_events.005`/`.006`), anointed heir transfer values/effects, lifecycle/duel/debug references, and Blood Power loc/docs (`blood-mage-blood-power.md`, `blood-mage-track-xp-power.md`).
- **6 Specialized Lifeforce Reservoirs (`common/modifiers/bm_lifeforce.txt`, `common/decisions/cast_magic/bm_transmute_lifeforce_decision.txt`, `events/bm_transmute_lifeforce_events.txt`)**: Expanded Transmute Lifeforce from 3 to 6 stacking reservoirs (`presence`, `fury`, `prosperity`, `shadows`, `focus`, `mojo`) carrying scaled-down Blood Power bonuses, `+0.1` `monthly_piety`, and `+5` native `monthly_*_lifestyle_xp_gain_add` per stack. Casting/reclaiming grants `+1`/`+2` `ancient` XP for Mojo and `+2`/`+4` matching track XP for the other 5 reservoirs. Extended `blood_magic_used_*` and `bm_recount_lifeforce_stacks_effect`.
- **Native Lifestyle XP on Channel Modifiers (`common/modifiers/bm_modifiers.txt`)**: Moved Channel Diplomacy/Martial/Stewardship/Intrigue/Learning (`+10`) and Experience Gain (`+5`) onto native `monthly_*_lifestyle_xp_gain_add` and removed `bm_empower_versatility_modifier`.
- **Ancient track (`lifestyle_bm_acolyte`, `lifestyle_blood_mage`, `lifestyle_bm_archmage`)**: Added `+2%` monthly Lifestyle XP (`monthly_lifestyle_xp_gain_mult = 0.02`) to each of the 5 milestones (`10`, `30`, `50`, `70`, `100` XP), totaling `+10%` per tier.
- **Promotion floors**: Added `+10%` monthly Lifestyle XP (`monthly_lifestyle_xp_gain_mult = 0.10`) to `lifestyle_blood_mage` base stats and `+20%` (`monthly_lifestyle_xp_gain_mult = 0.20`) to `lifestyle_bm_archmage` base stats.
- **Important actions (`common/important_actions/bm_important_actions.txt`, `localization/english/bm_important_actions_l_english.yml`)**: Added `bm_action_can_attune_lifeforce` (prompts unattuned player Blood Mages and opens `bm_attune_lifeforce_decision`) and `bm_action_can_trait_drain_prisoner` (combined notification for Tier 2+ player Blood Mages with a valid `trait_drain_prisoner_event_interaction` prisoner).
- **Silent yearly Ancient XP**: Removed the `bm_yearly_ancient_toast` popup from `blood_mage_yearly_events.001` in `events/bm_yearly_events.txt` and its localization key in `localization/english/bm_traits_l_english.yml` so the base `+1` yearly Ancient XP is granted silently.

### Other changes

- Updated `scripts/modifiers_allowlist.json`, `AGENTS.md`, `docs-ai/architecture/*`, and `RELEASE_NOTES.md` to match the new 6-reservoir system and native `monthly_*_lifestyle_xp_gain_add` modifiers.
