# v1.20.85: Add monthly Lifestyle XP gain to Ancient track and Mage/Archmage base traits

## Motivation

- Give the Ancient track a progression-focused Lifestyle XP bonus and preserve it on tier promotion floors for Blood Mage and Blood Archmage.

## Changes

### Key changes

- **Ancient track (`lifestyle_bm_acolyte`, `lifestyle_blood_mage`, `lifestyle_bm_archmage`)**: Added `+2%` monthly Lifestyle XP (`monthly_lifestyle_xp_gain_mult = 0.02`) to each of the 5 milestones (`10`, `30`, `50`, `70`, `100` XP), totaling `+10%` per tier.
- **Promotion floors**: Added `+10%` monthly Lifestyle XP (`monthly_lifestyle_xp_gain_mult = 0.10`) to `lifestyle_blood_mage` base stats and `+20%` (`monthly_lifestyle_xp_gain_mult = 0.20`) to `lifestyle_bm_archmage` base stats.
- **Important actions (`common/important_actions/bm_important_actions.txt`, `localization/english/bm_important_actions_l_english.yml`)**: Added `bm_action_can_attune_lifeforce` (prompts unattuned player Blood Mages and opens `bm_attune_lifeforce_decision`) and `bm_action_can_trait_drain_prisoner` (combined notification for Tier 2+ player Blood Mages with a valid `trait_drain_prisoner_event_interaction` prisoner).
- **Silent yearly Ancient XP**: Removed the `bm_yearly_ancient_toast` popup from `blood_mage_yearly_events.001` in `events/bm_yearly_events.txt` and its localization key in `localization/english/bm_traits_l_english.yml` so the base `+1` yearly Ancient XP is granted silently.

### Other changes

- Updated `docs-ai/architecture/blood-mage-traits.md` and `RELEASE_NOTES.md` to reflect the new Ancient track and tier base Lifestyle XP modifiers.
