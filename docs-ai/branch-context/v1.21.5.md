# v1.21.5: Require branch re-check before commit/push in AGENTS.md

## Motivation
- Prevent agents from committing or pushing to `main` when the working tree switches branches between turns (e.g., after a PR merge).

## Changes
### Key changes
- Replaced the **Blood Retinue (Knights)** Situation panel roster with **Court Blood Mages** (`bm_court_blood_mages`), tracking all Blood Mage courtiers (excluding Blood Golems) rather than only sworn knights.
- Updated `AGENTS.md` to require re-checking `git branch --show-current` immediately before committing/pushing, and branching `v1.21.<N+1>` if on `main` or detached `HEAD`.
