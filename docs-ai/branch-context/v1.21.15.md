# v1.21.15: AI Action Game Rules
PR: #210

## Motivation
- Give players direct campaign control over high-impact AI Blood Mage actions (Trait Drain, Memory Drain, and granting Blood Mage) without changing player availability.
  - Allows restricting these actions to landed AI rulers only or disabling them for AI entirely.

## Changes
### Key changes
- **AI Action Game Rules** (`bm_ai_trait_drain`, `bm_ai_memory_drain`, `bm_ai_grant_blood_mage`): Added three campaign game rules under Blood Mages.
  - **AI: Trait Drain** (`bm_ai_trait_drain`): `Yes` (default), `Landed Rulers Only` (`is_landed = yes`), or `No`; vetoes AI `drain_trait` in `bm_blood_drain`.
  - **AI: Memory Drain** (`bm_ai_memory_drain`): `Yes` (default), `Landed Rulers Only` (`is_landed = yes`), or `No`; vetoes AI `drain_memory` in `bm_blood_drain`.
  - **AI: Grant Blood Mage** (`bm_ai_grant_blood_mage`): `Yes` (default), `Landed Rulers Only` (`is_landed = yes`), or `No`; gates AI `ai_potential` in `grant_blood_magic_interaction`.
- **AI Rule Triggers** (`bm_ai_allowed_trait_drain_trigger`, `bm_ai_allowed_memory_drain_trigger`, `bm_ai_allowed_grant_blood_mage_trigger`): Centralized game-rule checks for the three AI actions.

### Other changes
- Updated `blood-mage-game-rules.md` and `RELEASE_NOTES.md`.

## AI behaviour tuning
- Blessing: AI prefers self (+150), then role-matched councillors; never grants Lifeforce.
- Heal: weighted by councillor skill; low-level non-family rarely healed for minor ailments.
- Prisoner drain: Trait > Memory > Minor > Major.
- Empower Bloodline and self buffs throttled (`ai_frequency = 36`, empower piety >= 300).
- Added `scripts/tally_ai_actions.py` to count AI action ratios from `debug.log`.
