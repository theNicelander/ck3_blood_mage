# v1.21.14: Egill Refactor, Tempering Duel Leak Fix & Script Deduplication
PR: #209
## Motivation
- Egill was recreated in every duel and the tempering duel never removed him.
  - Each tempering attempt left a stray 100-year-old Egill in the world.
- The geyser and tempering Egills were defined separately and differed.
- Trait drain, compat triggers, memory drain, blood artifact, and golem refuel scripts carried heavy duplicated boilerplate from v1.21.12-13.

## Changes
### Key changes
- **Shared Egill build** (`bm_create_egill_effect`): one definition for the geyser duel and the tempering duel.
  - Same traits, stats and trait XP in both duels.
  - Joins `house_skallagrimsson` when it exists; removed the dead `dynasty_myramenn` branch.
- **Tempering duel cleanup** (`bm_vanish_egill_effect`): Egill vanishes when the tempering chain ends.
  - Covers Back options, the Learning duel, and the Prowess duel result or refund.
  - Prowess duel keeps him until its result event.
- **Trait drain & overhaul compat deduplication** (`bm_trait_drain_execute_*`, `bm_compat_ek2_*`):
  - Extracted shared parameterized duel helpers (`bm_trait_drain_duel_fail_effects`, `bm_trait_drain_execute_vanilla_leveled_effect`, `bm_trait_drain_execute_single_effect`, `bm_trait_drain_execute_single_dual_xp_effect`, `bm_trait_drain_execute_single_purge_effect`, `bm_trait_drain_execute_tier4_effect`, `bm_trait_drain_execute_tier3_hist_effect`).
  - Kept all external overhaul trait IDs isolated at `bm_compat_*` call sites.
  - Simplified EK2 transformation and ranked/Hist checks via `bm_compat_ek2_has_transformation_trigger`, `bm_compat_ek2_can_drain_ranked_trigger`, `bm_compat_ek2_can_afford_tier4_trigger`, and `bm_compat_ek2_can_afford_hist_trigger`.
  - Reused `bm_can_drain_leveled_trait_from_target_trigger` in vanilla trait triggers.
- **Memory drain, blood artifacts & minor cleanups** (`bm_memory_drain_*`, `bm_forge_blood_artifact_effect`, `bm_refuel_blood_golem_effect`):
  - Extracted `bm_memory_drain_commit_leveled_cost_effect`, `bm_memory_drain_fail_toast_effect`, and `bm_can_afford_memory_drain_tracked_piety_trigger`.
  - Extracted `bm_create_forged_blood_artifact_effect` and moved the forge toast into `bm_forge_blood_artifact_effect`.
  - Extracted `bm_temper_duel_win_effect` and `bm_temper_duel_fail_effect`.
  - Extracted `bm_refuel_blood_golem_effect` across Grant Lifeforce and interpersonal events.
  - Reused `bm_ai_trait_drain_safety_modifier` in `seek_power.003.b`.

### Other changes
- Docs & skills:
  - Documented that event scopes do not persist across decisions (spawned NPC `exists` guards never hit).
  - Documented scripted-effect macro limits (`duel` weight `modifier` blocks and boolean params) in `common/AGENTS.md`.
  - Updated `add-overhaul-compat` skill with the parameterized trait-drain helper recipe.
