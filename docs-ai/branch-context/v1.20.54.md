# v1.20.54: Error Log Audit, Interaction Scoping & Script Fixes

## Summary & Motivation
Comprehensive audit and resolution of all error log issues, data-binding failures, missing localization keys, malformed trigger syntax, and unsafe scope links that remained in the mod after the `v1.20.53` refactor. The game was run prior to several recent commits; this update clears all genuine unresolved errors to ensure a clean error log.

## Core Concepts & Changes
- **Interaction Data-Binding Resolution**: Added `subject = scope:recipient` to `custom_description` blocks in `bm_union_interactions.txt` (`bm_consecrated_union_already_consecrated`) and `bm_mage_interactions.txt` (`bm_recipient_has_lifeforce_reserves`), and updated their localization strings (`bm_union_l_english.yml`, `bm_mage_interactions_l_english.yml`) from `[recipient.GetShortUIName]` to `[CHARACTER.GetShortUIName]`, eliminating `Failed to find type 'recipient'` engine data errors.
- **Missing Toast Localization**: Added missing `bm_purge_impurities_toast: "Purged Blood Impurities"` in `localization/english/bm_cast_blood_magic_self_l_english.yml`.
- **Purged Duplicate Localization Keys**: Removed redundant definitions of `bm_major_manifest_traits` and its aliases from `bm_cast_blood_magic_self_l_english.yml`, retaining their authoritative single definitions in `bm_channel_manifest_traits_l_english.yml`.
- **Illegal Localization Break Fix**: Replaced all literal `\x27` hex escape characters in `localization/english/bm_interpersonal_events_l_english.yml` with standard `'` apostrophes across all 6 lines, eliminating engine read warnings.
- **Deprecated Modifier Cleanup**: Completely purged all remaining dangling references to `resilience_attuned` from `bm_attunement_triggers.txt`, `bm_blood_magic_used_effects.txt`, `bm_blood_mage_story_custom_loc.txt`, `bm_modifiers_l_english.yml`, and `bm_blood_mage_story_l_english.yml`.
- **Event Option Syntax Fix**: Corrected `events/bm_blood_golem_events.txt` (`blood_golem.002`) where `show_as_unavailable = { always = yes }` was mistakenly placed inside `trigger = { ... }` across 7 shaping options, moving it to the `option` level and eliminating `Unknown trigger: show_as_unavailable` errors.
- **Event Theme Correction**: Changed invalid event theme `theme = romance` in `bm_interpersonal_events.0001` (`events/bm_interpersonal_events.txt`) to valid basegame theme `theme = love`.
- **Null-Safe Heir Scoping**: Replaced unsafe `this = scope:actor.primary_heir` comparison in `common/character_interactions/bm_inscribe_rune_other.txt` with native `is_primary_heir_of = scope:actor`, preventing unset scope errors on unlanded or heirless characters.
- **Lifedrain Debug Log Scope Shielding**: Wrapped `debug_log` in `lifedrain_execution_effect` (`common/scripted_effects/bm_drain_all_prisoners_effects.txt`) inside `if = { limit = { exists = scope:victim exists = scope:executioner } }`, avoiding `Character '(no character)' is not valid` errors during event option tooltip evaluation or empty prisoner iterations.

## Key Decisions
- Chose `[CHARACTER.GetShortUIName]` with explicit `subject = scope:recipient` over static text: preserves dynamic character names in interaction requirement tooltips while adhering to CK3's trigger localization data context.
- Fixed `show_as_unavailable` placement in `blood_golem.002` rather than removing it: preserves the mod's "Nothing hidden, but often unavailable" principle so players see all 7 golem traits grayed out once acquired.
- Shielded `lifedrain_execution_effect` debug logging with an existence check rather than stripping debug info: preserves vital execution tracing in playtests while silencing spurious tooltip evaluation errors.
