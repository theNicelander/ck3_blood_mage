# v1.20.58: Blood Universities Regular Conversion & Old Age Rejuvenation Simplification

## Summary & Motivation
Overhaul Blood Universities (`bm_buildings.txt`) from restricted duchy capital holdings into standard regular buildings constructible in all holding types (castles, cities, temples, and tribal settlements). Replace personal cultural fascination and lifestyle XP multipliers with robust development and control growth engines: flat development growth (`+0.1` to `+0.4`), percentage development growth factors (`+5%` to `+20%`), and monthly county control growth (`+0.1` to `+0.4`) under `county_modifier`.
Rework old age degenerative trait healing (`infirm`, `clouded_eyes`, `fragile_bones`, `withering_mind`, `faltering_heart`) in the Rejuvenate Old Age event (`bm_heal_old_age.0001`): consolidate from 3 options down to 2 options per trait (11 total options including Cancel), auto-curing traits when track XP is within removal threshold (<= 20 XP for Minor, <= 50 XP for Major) and reducing XP otherwise, accompanied by dynamic button labels and interface toasts.

## Core Concepts & Changes
- **Old Age Trait Rejuvenation Simplification (`events/bm_heal_old_age_events.txt` & `localization/english/bm_heal_old_age_l_english.yml`)**:
  - Consolidated event options from 16 to 11 (2 per trait + 1 cancel).
  - **Minor Rejuvenation** (50 Piety + Minor Lifeforce, +1 Benediction XP):
    - Track XP <= 20: completely removes trait via `remove_trait = <trait>` with `Old Age Affliction Purged` toast.
    - Track XP > 20: reduces track XP by -20 via `add_trait_xp = { trait = <trait> track = <trait> value = -20 }` with `Old Age Affliction Soothed` toast.
    - Dynamic button label: shows `Soothe <Trait> (Cure)` if track XP <= 20, or `Soothe <Trait> (-20 XP)` otherwise.
  - **Major Rejuvenation** (150 Piety + Major Lifeforce, +2 Benediction XP):
    - Track XP <= 50: completely removes trait via `remove_trait = <trait>` with `Old Age Affliction Purged` toast.
    - Track XP > 50: reduces track XP by -50 via `add_trait_xp = { trait = <trait> track = <trait> value = -50 }` with `Old Age Affliction Soothed` toast.
    - Dynamic button label: shows `Rejuvenate <Trait> (Cure)` if track XP <= 50, or `Rejuvenate <Trait> (-50 XP)` otherwise.
  - Removed all separate redundant 3rd "Cure" options.

## Key Decisions
- **Dynamic Auto-Cure over Redundant Separate Options**: Having a separate "Cure" button that costs Major Lifeforce while Major Rejuvenation also costs Major Lifeforce created confusion and forced characters with low XP (e.g. 0-10 XP) to navigate clunky sub-options. Auto-curing whenever track XP is reduced to 0 (or starts below the tier's XP reduction power: <=20 for Minor, <=50 for Major) makes rejuvenation natural, responsive, and clean.
- **Regular Building vs Duchy Capital**: Duchy capital slots are strictly limited to 1 per duchy, locking out counts and tribal rulers. Converting Blood Universities to regular buildings enables blood mages and knights to cultivate universities across any holding, including tribal lands.
- **Focus on Realm Infrastructure over Character Stats**: Cultural fascination mult and lifestyle XP mult overlap heavily with standard character lifestyles and cultural traditions. Replacing them with flat and percentage development growth alongside county control growth cements Blood Universities as potent county development hubs.
- **Consolidation under `county_modifier`**: As regular buildings, county growth modifiers are placed under `county_modifier` so they affect the county regardless of whether the barony is a duchy capital.
