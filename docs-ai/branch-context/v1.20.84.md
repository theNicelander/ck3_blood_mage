# v1.20.84: Rework House Covenants to Blood Mage tracks

## Motivation

- House Covenants previously granted yearly XP to `lifestyle_blood_power` tracks, decoupling house progression from the primary `lifestyle_blood_mage` discipline tracks.
  - Reworking covenants to feed `lifestyle_blood_mage` tracks directly aligns house-wide rituals with core Blood Mage progression and removes automatic `lifestyle_blood_power` trait injection.

## Changes

### Key changes

- **Yearly Covenant XP Pulse (`blood_mage_yearly_events.002`)**:
  - Grants `+1` XP in the matching `lifestyle_blood_mage` track (checked across Acolyte, Blood Mage, and Archmage via `bm_has_track_xp_any_tier_trigger < 100`).
  - Adjusted yearly roll chances by covenant tier to **25% (Tier I) / 50% (Tier II) / 100% (Tier III)**.
  - Removed automatic `lifestyle_blood_power` trait assignment.
- **Renamed Covenants & Internal IDs**:
  - `dynasty_blood_benediction_modifier_*` / `bm_covenant_benediction` → **Covenant of Benediction** (`benediction`)
  - `dynasty_blood_bloodlust_modifier_*` / `bm_covenant_bloodlust` → **Covenant of Bloodlust** (`bloodlust`)
  - `dynasty_blood_bloodline_modifier_*` / `bm_covenant_bloodline` → **Covenant of Bloodline** (`bloodline`)
  - `dynasty_blood_hematurgy_modifier_*` / `bm_covenant_hematurgy` → **Covenant of Hematurgy** (`hematurgy`)
  - `dynasty_blood_enlightenment_modifier_*` / `bm_covenant_enlightenment` → **Covenant of Enlightenment** (`enlightenment`)
  - `dynasty_blood_ancient_modifier_*` / `bm_covenant_ancient` → **Covenant of the Ancient** (`ancient`)
  - Updated `bm_empower_bloodline_decision` widget icons to the matching `trait_level_tracks/*.dds` assets.

### Other changes

- Updated `AGENTS.md` to require renaming internal IDs on reworked features and to forbid committing or pushing directly to `main`, and added a tracked `.githooks/pre-commit` hook blocking commits on `main`.
- Synced `docs-ai/architecture/` (`blood-mage-dynasty.md`, `blood-mage-track-xp.md`, `blood-mage-track-xp-mage.md`, `blood-mage-track-xp-power.md`) and `RELEASE_NOTES.md`.
