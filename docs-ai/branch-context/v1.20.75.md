# v1.20.75: Raise Default Devotion Level Cap to 8

## Motivation

- Enable progression beyond Level 5 (Religious Icon): In vanilla CK3, the default devotion level cap is 5, restricting higher devotion tiers (Level 6: Divine, Level 7: Demigod, Level 8: Godlike) primarily to Mandala governments.
- Universal progression for religious and occult rulers: All rulers and governments can now accumulate devotion up to Level 8 (22,500 Piety), fully utilizing the engine's built-in higher tiers, modifiers, memories, and mod mechanics that scale per piety level.
- Clean modular define (zero vanilla overwrites): Avoid shadowing the 1,900-line vanilla `00_defines.txt` file by using a dedicated modular define file (`bm_defines.txt`), guaranteeing total compatibility with future game patches and other mods.

## Changes

### Key changes

- **Modular Piety Level Cap Override (`common/defines/bm_defines.txt`)**:
  - Added modular define setting `NCharacter = { DEFAULT_PIETY_LEVEL_CAP = 8 }`.
  - Characters of all government types now default to a maximum devotion level of 8 without overwriting vanilla files.
  - Characters can progress through Level 6 (Divine, 13,000 Piety), Level 7 (Demigod, 17,000 Piety), and Level 8 (Godlike, 22,500 Piety), benefiting from vanilla modifiers and scaling Blood Mages devotion multipliers.

### Other changes

- Updated `docs-ai/architecture/blood-mage-shared-scripting.md` documenting modular `bm_defines.txt` define.
- Updated `RELEASE_NOTES.md` adding `v1.20.75` entry and devotion cap bullet in Blóðtrú Religion section.
