# v1.20.89: Allow Blood Acolytes to channel Major Lifeforce in Transmute Lifeforce

## Motivation

- `bm_transmute_lifeforce_decision` was already visible to all Blood Mage tiers (`is_blood_mage_any_tier_trigger`), and Blood Acolytes can obtain Major Lifeforce (e.g., via Minor Condensation, Blood Hunts, or executions), yet the **Channel Major Lifeforce** option in `bm_transmute_lifeforce.0001` remained gated behind `is_blood_mage_tier_2_or_higher_trigger = yes`.

## Changes

### Key changes

- **Transmute Lifeforce (`bm_transmute_lifeforce.0001`)**:
  - Changed the `bm_transmute_lifeforce.0001.major` option trigger from `is_blood_mage_tier_2_or_higher_trigger = yes` to `is_blood_mage_any_tier_trigger = yes` so Blood Acolytes (`lifestyle_bm_acolyte`) and all higher tiers can channel Major Lifeforce into specialized reservoirs.
