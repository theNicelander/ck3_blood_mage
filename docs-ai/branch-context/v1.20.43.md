# v1.20.43: Fix Seek Power Event Portraits, Character Identity & Blood Empowerment UI Pairing

## Summary & Motivation

1. **Event Window Portraits Fix**: Portraits in `seek_power.001`, `.002`, `.003`, `.004`, and `.006` were defined at the bottom of the event script blocks (after all `option = { ... }` blocks). In Paradox Jomini engine, GUI event windows ignore portrait declarations placed after options, rendering empty backgrounds. All portrait blocks are now moved to the top of each event definition immediately after `theme = ...` and before `immediate = { ... }` / `option = { ... }`.
2. **Dual-Character Staging in Encounter**: In `seek_power.003`, the player renders on `left_portrait`, the traveler/minor noble renders in 3D on `right_portrait` (`animation = beg`), and when spawned (50% chance), the sworn escort knight renders in `lower_right_portrait` guarded by `trigger = { exists = scope:escort_knight }`. This eliminates the null scope error (`Failed to find applicable culture set for character with id 4294967295`) when the escort does not spawn.
3. **Explicit Character Names & Prowess**: Updated `bm_seek_power_l_english.yml` to display full character names with clickable tooltips and prowess ratings in event descriptions (`[recipient.GetUIName] ([recipient.GetProwess] [prowess|E])`, `[escort_knight.GetUIName] ([escort_knight.GetProwess] [prowess|E])`) and in button option titles and toasts (`[recipient.GetFirstNameNoTooltip]`, `[escort_knight.GetFirstNameNoTooltip]`).
4. **Blood Empowerment UI Pairing**: Characters now always gain base `lifestyle_blood_empowerment` (0 XP in all tracks) simultaneously when acquiring either `lifestyle_blood_mage` or `lifestyle_blood_knight`. Because CK3 character sheets display traits in chronological order of acquisition, gaining them together ensures they appear directly adjacent to one another in the character UI.
5. **Slaughter 50 Devotion Milestone Simplification**: Completely eliminated the non-existent CK3 modifier workaround (`knight_limit_per_piety_level` via stacked `bm_slaughter_devotion_knights_modifier` and `bm_update_slaughter_devotion_knights_effect`), which was erroneously leaking `5 times - Gains Slaughter Devotion` into tooltips of unrelated interactions like Manifest Lifeforce. Slaughter 50 now cleanly grants native `martial_per_piety_level = 1` and `prowess_per_piety_level = 1`.
6. **Grimoire & Rite Cooldown Localizations**: Added complete player-facing sibling localization keys and `custom_description` wrappers for `bm_improve_education_cooldown` (and sibling cooldowns `bm_new_education_cooldown`, `bm_blood_golem_cooldown`, `bm_blood_rune_cooldown`, `bm_blood_rune_other_cooldown`, `bm_channel_bloodline_cooldown`, `bm_manifest_traits_cooldown`), preventing raw snake_case flag identifiers from displaying in unavailable option tooltips.

## Key Decisions

- **Free First Pick with 3-Year Respec Lock**: Lowers the barrier of entry for newly initiated Blood Mages and Blood Knights so they can choose their path without immediately needing to harvest/manifest Minor Lifeforce, while establishing a meaningful 3-year commitment and a non-trivial respec cost (100 Piety + 1 Minor Lifeforce) to deter trivial discipline hopping.
- **Native Engine Scaling over Scripted Pseudo-Modifiers**: CK3 lacks a native `knight_limit_per_piety_level` modifier. Attempting to emulate it with script while-loops repeatedly stripping and stacking modifiers caused tooltip leakage ("5 times - Gains Slaughter Devotion") during unrelated XP gains (Manifest Lifeforce). Replacing the mechanic with native `martial_per_piety_level = 1` provides clean, reliable military power scaled by devotion with zero script overhead.
- **`lower_right_portrait` for Escort Knight**: Standard `character_event` windows in CK3 do not have a 3D `center_portrait` widget in `character_event.gui` (which only supports `left_portrait`, `right_portrait`, `lower_left_portrait`, `lower_center_portrait`, and `lower_right_portrait`). Staging the traveler on `right_portrait` and the escort knight on `lower_right_portrait` cleanly groups the bodyguard with their noble on the right side of the screen, while leaving `left_portrait` for the player.
- **Safe Null Scope Guards**: Guarded `lower_right_portrait` with `trigger = { exists = scope:escort_knight }` and `seek_power.006` `right_portrait` with `trigger = { exists = scope:duel_opponent }` to ensure zero runtime culture / scope errors in `error.log`.
- **Base 0 XP Blood Empowerment**: Added with 0 XP across all tracks, granting no base stats until actively leveled via Major Magic or specific rewards, preserving balance while achieving desired visual adjacent grouping in the traits interface.
