# v1.20.51: Manifest Trait Polish, Condense XP Rebalance & Tsushima Eminent Holy Site

## Summary & Motivation
This branch delivers three targeted improvements:
1. Renames the Major Blood Magic Grimoire congenital trait option from "Channel Lifeforce: Manifest Perfection" to "Manifest Trait" (`bm_cast_blood_magic_major.001.manifest_traits`), adhering to concise and direct UI naming standards, while enforcing option persistence with `show_as_unavailable = { always = yes }` and adding an explicit custom requirement description for maxed rank 2 traits so players always see the rite grayed out rather than hidden.
2. Recalibrates the Ancient track XP rewards for condensing into Superior Lifeforce (`bm_cast_blood_magic_major.001.condense`) to award +3 Ancient XP on Critical Success and Success (+1 XP on failure).
3. Promotes Tsushima (`tsushima`, county `c_tsushima`) to an eminent holy site for the Japanese blood faith Ketsudō (`ketsudo_faith`), granting faith-wide Prowess per Piety Level and aligning with its role as the Eastern initiation geyser site.

## Core Concepts & Changes
- **Option Renaming (`localization/english/bm_channel_manifest_traits_l_english.yml`)**:
  - Renamed `bm_cast_blood_magic_major.001.manifest_traits` from `"Channel Lifeforce: Manifest Perfection"` to `"Manifest Trait"`.
  - Added `bm_manifest_traits_max_rank_2_tt` / `NOT_bm_manifest_traits_max_rank_2_tt` informing players when all congenital traits (Intellect, Physique, Beauty) have reached rank 2.
- **Option Visibility & Tooltip Polish (`events/bm_cast_blood_magic_major_events.txt`)**:
  - Wrapped rank 2 congenital trait gating inside `custom_description = { text = bm_manifest_traits_max_rank_2_tt ... }`.
  - Guaranteed option remains persistently visible and grayed out when requirements (piety, cooldown, devotion, max traits) are not met via `show_as_unavailable = { always = yes }`.
- **Condense Superior Lifeforce XP Rebalance (`events/bm_cast_blood_magic_major_events.txt`)**:
  - Rebalanced the Learning duel Ancient XP rewards for `bm_cast_blood_magic_major.001.condense` (1 Minor + 1 Major Lifeforce + 250 Piety):
    - **Critical Success**: `+3` Ancient XP (was `+8`).
    - **Success**: `+3` Ancient XP (was `+5`).
    - **Fail**: `+1` Ancient XP (was `+2`).
    - **Critical Fail**: `0` Ancient XP (unchanged).
- **Tsushima Eminent Holy Site (`common/religion/faith_types/bm_ketsudo.txt`)**:
  - Moved `tsushima` from `holy_sites` to `eminent_holy_sites` in `ketsudo_faith`.
  - Ketsudō now has 7 eminent holy sites (`tsushima`, `yamashiro`, `kamakura`, `mount_fuji`, `mount_aso`, `mount_osore`, `gyeongju`) and 20 regular holy sites.
  - Controls check broadcasts `faith_character_modifier` (+1 Prowess per Piety Level) globally to all Ketsudō followers while stacking with the county holder's bonus.
- **Architecture & Documentation Alignment**:
  - Updated all architecture references (`blood-mage-decisions.md`, `blood-mage-duels-and-education.md`, `blood-mage-events-overview.md`, `blood-mage-magic-tiers.md`, `blood-mage-track-xp.md`, `blood-mage-lifeforce.md`, `blood-mage-blood-knight.md`, `blood-mage-religions.md`) to reflect the Manifest Trait naming, Condense XP, and 7 Ketsudō eminent holy sites.

## Key Decisions
- **Concise Naming over Verbose Flavour**: Replaced "Channel Lifeforce: Manifest Perfection" with "Manifest Trait" to align with other concise Major Grimoire options ("Condense Lifeforce", "Enhance Education", "Channel Blood Power").
- **Persistent Visibility via `show_as_unavailable`**: Maintained `show_as_unavailable = { always = yes }` and clear requirement tooltips so players can always see the ritual exists and what prerequisites are needed.
- **Calibrated Ancient XP**: Standardized Condense Superior Lifeforce at +3 Ancient XP on successful manifestation (mirroring the stepped progression above Minor-to-Major condensation's +2 Ancient XP) while preserving the Learning skill contest and a modest +1 XP consolation on failed distillation.
- **Tsushima Eminent Status**: Elevated Tsushima to an eminent holy site for Ketsudō, mirroring Reykjavik's eminent status in Blóðtrú as the primary geographical anchor for initiation duels.
