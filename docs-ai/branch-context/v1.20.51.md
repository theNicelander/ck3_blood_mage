# v1.20.51: Manifest Trait Polish, Condense XP Rebalance & v1.20.50.a–f Audit Fixes

## Summary & Motivation
Renames the Major Blood Magic Grimoire congenital trait option from "Channel Lifeforce: Manifest Perfection" to "Manifest Trait" (`bm_cast_blood_magic_major.001.manifest_traits`), enforces option persistence with `show_as_unavailable = { always = yes }`, and recalibrates the Ancient track XP rewards for condensing into Superior Lifeforce (`bm_cast_blood_magic_major.001.condense`) to award +3 Ancient XP on Critical Success and Success (+1 XP on failure). Additionally, resolves 18 post-merge audit issues across the `v1.20.50.a`–`v1.20.50.f` feature streams (engine/syntax bugs, missing court position DDS asset, incomplete positive-target trigger rollouts, and toast/stack-recount rule violations).

    - **1. Success (Hard to get, weight 20):** Major Lifeforce, high loot/prestige, +2 Slaughter/Hematurgy XP, clean victory with no injuries or penalties.

    - **4. Critical Fail (Weight 20):** Character is mauled/overpowered; Wounded (`increase_wounds_no_death_effect = { REASON = fight }`), 0 Lifeforce, +20 Stress, and lost resources (-25 Gold, -50 Piety, or -15 to -25 Prestige).

    - `seek_power.008` (Apex Beast): `skill = prowess` vs `value = 30`.
    - `seek_power.010` (Outlaw Camp): `skills = { prowess martial }` vs `value = 24`.
    - `seek_power.009` (Isolated Homestead): `skills = { intrigue prowess }` vs `value = 16`.
    - `seek_power.011` (Rival Occultist): `skills = { prowess learning }` vs `value = 18`.
  - Removed artificial Vegvísir rune hazard elimination modifiers from these direct combat encounters.

## Key Decisions
- **Concise Naming & Persistent Visibility**: Replaced "Channel Lifeforce: Manifest Perfection" with "Manifest Trait" and maintained `show_as_unavailable = { always = yes }`.
- **Calibrated Ancient XP**: Standardized Condense Superior Lifeforce at +3 Ancient XP on successful manifestation.
- **Single Active Anointed Heir per Ruler**: Tracking `var:bm_anointed_heir` on the parent and clearing `bm_anointed_heir_modifier` upon succession prevents an anointed child from repeatedly inheriting Lifeforce and 25% XP from unrelated dying dynasty members.
- **Tsushima Eminent Elevation**: Promoted Tsushima to an eminent holy site for Ketsudō, mirroring Reykjavik's eminent status in Blóðtrú as the primary geographical anchor for initiation duels.
- **Standardized Yearly Pulse on Jan 1st**: Hooking `yearly_playable_pulse` ensures players receive predictable feedback on the game's standard yearly rollover date, while keeping unplayable AI characters on `random_yearly_everyone_pulse` to prevent double-firing and distribute engine background load.
- **Blood Hunt 4-Tier Duel Overhaul**: Replaced unchallenging binary rolls in violent wilderness encounters with high-stakes 4-tier resolutions (Clean Kill, Mixed Wounded, Escape, and Mauled/Defeat). Wounding uses vanilla `increase_wounds_no_death_effect = { REASON = fight }` to prevent instant death while escalating injuries fairly. Natural combat hazards are no longer bypassed by navigation runes.
