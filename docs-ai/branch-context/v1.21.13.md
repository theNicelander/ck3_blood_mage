# v1.21.13: Trim Niche Modded Blood Memory Drain Compat

## Motivation
- Sub Rosa and Councillor's Experience are uncommon mods whose unguarded trait keys add unnecessary parse-time `error.log` warnings in vanilla sessions.
  - Keeping only major overhauls (AGOT, LotR: Realms in Exile, Elder Kings 2) and Commander+ 1.21 reduces startup log noise while retaining widely used mod support.

## Changes
### Key changes
- **Blood Memory Drain Compat** (`bm_compat_memory_triggers.txt`, `bm_memory_drain_effects.txt`, `bm_compat_memory_drain_events.txt`):
  - Removed Sub Rosa (9 traits) and Councillor's Experience (5 traits) from `bm_compat_memory_drain` (`bm_compat_memory_drain.0006` and its hub option).
  - Retained AGOT, LotR: Realms in Exile, Elder Kings 2, and Commander+ 1.21 Blood Memory Drain support.

### Other changes
- Synced `docs-ai/architecture/blood-mage-interactions.md`, `.agents/skills/debug-ck3-logs/SKILL.md`, and `RELEASE_NOTES.md`.
