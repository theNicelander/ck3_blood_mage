# v1.20.52: PR Workflow & Branch Context Verification Rule

## Summary & Motivation
Institutionalize mandatory branch context document verification and full-scope synthesis when creating, updating, or merging pull requests to prevent parallel feature work from being under-reported or omitted. Additionally, fix Grimoire event option suppression where unavailable options were silently hidden once 4 options were displayed.

## Core Concepts & Changes
- **PR Lifecycle & Context Verification (`manage-pr` Skill)**: Created `.agents/skills/manage-pr/SKILL.md` detailing step-by-step procedures to audit `docs-ai/branch-context/<branch>.md` against `git log origin/main..HEAD`, ensure branch docs are completely accurate prior to PR actions, compose comprehensive multi-section descriptions, and preserve full branch scopes in merge commit messages.
- **Rule Enforcement (`.agents/rules/pr-context.md`)**: Updated rule item 7 to strictly mandate branch context verification before PR creation, updating, and merging, forbidding single-commit truncation or dropping parallel features.
- **Agent Instructions (`AGENTS.md`)**: Linked `manage-pr` skill into workflow step 3 and updated workflow step 10 to mandate branch document audits.
- **Blood Knight Yearly Pulse Progression Audit**: Removed unintended annual passive +1 Enlightenment XP tick and toast from `blood_mage_yearly_events.004` ([events/bm_yearly_events.txt](file:///Users/clarabotet/Documents/Paradox%20Interactive/Crusader%20Kings%20III/mod/ck3_blood_mage/events/bm_yearly_events.txt)) and pruned orphaned toast keys in [localization/english/bm_traits_l_english.yml](file:///Users/clarabotet/Documents/Paradox%20Interactive/Crusader%20Kings%20III/mod/ck3_blood_mage/localization/english/bm_traits_l_english.yml). Passive annual XP is strictly reserved for the Ancient track (+1 XP) and active discipline attunements.
- **Grimoire Option Suppression Fix (`EVENT_OPTIONS_SHOWN_HIDE_UNAVAILABLE`)**: Overrode graphic define `NGui = { EVENT_OPTIONS_SHOWN_HIDE_UNAVAILABLE = 10 }` in modular file `common/defines/graphic/bm_graphics.txt`. Vanilla CK3 defaults this threshold to 4, which suppressed any unavailable options relying on `show_as_unavailable` (such as *Manifest Traits* or *Enhance Education* when on cooldown) as soon as 4 options were displayed in Grimoire events (`bm_cast_blood_magic_major.001`, `bm_cast_blood_magic_superior.001`, `bm_cast_blood_magic_minor.001`). Raising this to 10 ensures all options remain visible and grayed out with requirement tooltips according to the mod's "Nothing hidden, but often unavailable" principle without dividing into sub-menus or pagination.
- **Influence Personality Culture Conversion**: Extended the Influence Personality ritual (`bm_reshape_personality_interaction` and `bm_reshape_personality.0001`) allowing Blood Mages and Blood Knights to expend Major Lifeforce and 250 Piety to rewrite a relationship target's culture to their own (`set_culture_same_as = root`). Resolved through the same Learning contest (+4 Enlightenment XP on victory, +1 on failure with 1-year lockout); includes grayed-out option visibility when culture already matches.

## Key Decisions
- Placed the requirement in both the always-on rule (`pr-context.md`) and a dedicated actionable skill (`manage-pr`), ensuring any agent running PR actions cannot miss the requirement.
- Strictly enforced earned power: XP must be earned through active player actions, with only Ancient (+1 XP/yr) and Attunements (+1 XP/yr) granted passively on New Year ticks. Blood Knights no longer receive passive yearly Enlightenment XP.
- Overrode `EVENT_OPTIONS_SHOWN_HIDE_UNAVAILABLE = 10` via a modular define file rather than altering event structure with pagination or sub-menus, adhering to user direction and keeping all blood magic spells directly accessible and visible in the Grimoire modal.
- Integrated culture conversion as a direct choice in the first event of Influence Personality (`bm_reshape_personality.0001`), resolving directly into the Learning duel and consuming Major Lifeforce without requiring a secondary trait selection screen.
