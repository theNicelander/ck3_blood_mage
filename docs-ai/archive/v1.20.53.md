# v1.20.53: Cast Blood Magic Inline Option-List Decision Widgets

## Summary & Motivation
Refactor Cast Blood Magic decisions (Minor, Major, Superior) into native CK3 1.20 inline option-list decision widgets (`decision_view_widget_option_list_generic`). This replaces the event-based popup Grimoires with native scrollable decision option drawers where all spells remain permanently visible, directly selectable, and cleanly grayed out with red requirement tooltips when prerequisites or cooldowns are not met. Completely removes the global engine define override (`common/defines/graphic/bm_graphics.txt`), restoring 100% zero basegame modification footprint.

## Core Concepts & Changes
- **Remove Define Override**: Deleted `common/defines/graphic/bm_graphics.txt` and its directory, reverting `EVENT_OPTIONS_SHOWN_HIDE_UNAVAILABLE` to the vanilla default (4) without risking any side effects on basegame character events.
- **Decision Option Widgets**: Converted all three Cast Blood Magic decisions (`bm_cast_blood_magic_minor_decision`, `bm_cast_blood_magic_major_decision`, `bm_cast_blood_magic_superior_decision`) in `common/decisions/cast_magic/bm_cast_blood_magic.txt` into modern inline option-list widgets with `show_from_start = yes`, 45×45 DDS icons, and red failure tooltips on unavailable choices.
- **Minimal Decision Descriptions**: Replaced long lore paragraphs in top-level decision descriptions with concise 1-line action prompts (`"Select a minor/major/superior rite to cast."`), maximizing vertical screen real estate for the scrollable option list.
- **Legacy Events Removal**: Deleted obsolete entry event files `events/bm_cast_blood_magic_minor_events.txt`, `events/bm_cast_blood_magic_major_events.txt`, and `events/bm_cast_blood_magic_superior_events.txt`.
- **Sub-Event Back Navigation**: Updated "Back / Return to Grimoire" cancel options across sub-events (`bm_education_master_events.txt`, `bm_education_new.txt`, `bm_education_enhance.txt`, `bm_carve_galdrastafir_events.txt`, `bm_blood_power_event.txt`) to cleanly exit rather than attempting to trigger removed entry events.
- **Localization & Tooltips**: Standardized option list items with identical `value`, `localization`, and `current_description` identifiers across Minor, Major, and Superior decisions; added missing option names and hover `<item_key>_tooltip` definitions queried by `[Entry.GetTooltip]` (e.g. `bm_major_channel_power_tooltip`, `bm_major_condense_tooltip`, `bm_superior_master_education_tooltip`), resolving raw key displays and missing tooltips; added confirm aliases (`BM_CAST_BLOOD_MAGIC_NEXT_STEP_BUTTON`) and backward-compatibility aliases; fixed missing Blóðtrú High God alternate deity localization keys (`blodtru_high_god_name_alternate` and `blodtru_high_god_alternate`).
- **PR Title & Heading Gameplay Focus Rule**: Updated `.agents/rules/pr-context.md`, `.agents/skills/manage-pr/SKILL.md`, and `AGENTS.md` workflow step 10 to mandate that unless a branch is exclusively documentation or AI rules, PR titles and merge commit headings must strictly focus on player-facing gameplay content, completely excluding meta fluff (such as PR workflow, branch verification, or documentation meta).
- **Covenant Localization Syntax Fix**: Replaced unescaped square brackets `[None]`, `[Minor]`, and `[Major]` with parentheses `(None)`, `(Minor)`, and `(Major)` across all 7 house covenants in `localization/english/bm_channel_lifeforce_l_english.yml`, eliminating the CK3 engine data-binding command parse errors that resulted in `ERROR:[Minor]` and `ERROR:[Major]` displays in the decision widget.
- **Standalone Galdrastafir Stave Decision**: Replaced the event-based stave selection (`events/bm_carve_galdrastafir_events.txt` -> `bm_galdrastafir.001`), which suppressed all options beyond Vegvísir due to the engine option cap, with a native standalone inline option-list decision `bm_carve_galdrastafir_decision` (`common/decisions/cast_magic/bm_carve_galdrastafir_decision.txt`) shown exclusively to characters possessing `superior_blood_rune_modifier`. Displays all 5 staves (Vegvísir, Ægishjálmur, Feingur, Nábrókarstafur, Hulinhjálmur) with their dedicated 120×120 DDS icons and red failure tooltips on the already-borne stave; costs 500 Piety (`bm_carve_galdrastafir_piety_cost`) and 1 Major Lifeforce with a 5-year decision cooldown.
- **Grimoire Major Stave Removal**: Removed the `bm_major_galdrastafir` item and its event trigger from `bm_cast_blood_magic_major_decision`, purged legacy event file `events/bm_carve_galdrastafir_events.txt`, and removed redundant `bm_swap_capstone_cost_effect` and `bm_capstone_rune_cooldown` flag.
- **Empower Dynasty Benediction XP**: Updated `bm_empower_dynasty` in `events/bm_blood_power_event.txt` to award `+3` Benediction XP (`TRACK = benediction`) instead of Enlightenment XP.
- **Blood Knight House Covenant Benediction XP Harmonization**: Updated `bm_upgrade_house_covenant_effect` (`common/scripted_effects/bm_empower_bloodline_effects.txt`) and the annual covenant pulse `blood_mage_yearly_events.002` (`events/bm_yearly_events.txt`) so that Blood Knights gain Benediction track XP (`+3` Tier I, `+5` Tier II, `+10` Tier III, and `+1` yearly pulse) instead of Vanguard XP, harmonizing with their shared Benediction mastery.
- **Blood Hunt Traveler Encounter Prowess Scaling**: Scaled the probability of encountering the wandering warrior and escort knight road encounter (`seek_power.003`) in the Blood Hunt dispatcher (`seek_power.001`) dynamically to the hunter's Prowess clamped between 20% and 50% via `bm_seek_power_traveler_chance_value` (equal to Prowess score, e.g. 30 Prowess = 30% chance, 47 Prowess = 47% chance). If not selected, cleanly falls back to the remaining 6 wilderness encounters. Added comprehensive debug logging to trace dispatcher and knight spawn execution.

## Key Decisions
- Chose Option 4 (Inline Option-List Decision Widget) over global define modifications or multi-page event pagination: provides a unified, scrollable interface in the decision view that natively supports arbitrary option counts without engine suppression.
- Kept top-level decision descriptions strictly minimal to conserve vertical drawer height and ensure immediate visibility of ritual items.
- Extracted Galdrastafir Stave carving into a dedicated standalone option-list decision gated on Superior Blood Rune modifier, resolving the single-option event display bug while keeping all 5 staves cleanly visible and grayed out when already selected.
- Preserved all sub-event workflows (Blood Power track selection, Manifest Traits, and Education ascension) called from the decision widget's effect dispatch.
