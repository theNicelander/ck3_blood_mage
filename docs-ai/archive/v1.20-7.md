# v1.20-7

## Summary & Motivation

This branch overhauls holy sites across all Quintessence faiths (aligning Eminent vs. Regular sites with modern European/Mediterranean capitals), introduces the "Challenge the Blood Mage of Reykjavík" decision and duel system, modernizes faith tenets, adds an explicit Christian syncretic faith variant, and introduces a standalone CK3 file inspection script (`read_ck3.py`) documented in agent rules.

## Core Concepts & High-Level Changes

- **Holy Site Network Reorganization (Eminent vs. Regular)**:
  - **Eminent Holy Sites (`eminent_holy_sites_max = 25`)**: Defined for universal spiritual centers, power capitals, and major historical centers granting non-health bonuses (piety multipliers, stats per piety level, etc.):
    - Iceland centers: `talknafjordur`, `reykjavik`
    - Major Western/Central capitals: `london`, `madrid`, `oslo`, `paris`, `berlin`
    - Prominent historical/religious centers: `rome`, `constantinople`, `jerusalem`, `mecca`, `olympus`, `kiev`, `athens`, `beirut`, `damascus`
  - **Regular Holy Sites (Health / Lifespan / Plague Resistance)**:
    - Retained existing custom European regional sanctuaries.
    - Added 21 missing European, Balkan, Caucasian, and Mediterranean capitals from base game titles (`ck3-full`): `belgrade`, `sarajevo`, `podgorica`, `skopje`, `tirana`, `pristina`, `minsk`, `chisinau`, `tbilisi`, `yerevan`, `baku`, `andorra`, `vaduz`, `san_marino`, `cairo`, `tripoli`, `tunis`, `algiers`, `rabat`, `ankara`, `amman`.
    - Removed non-capitals or obsolete entries: `ranaheim`, `cordoba`, `carnac`, `colonea`, `medina`, `carthage`, `sinai`, `alexandria`, `cologne`, `fes`, `santiago`.
  - Holy site localization added for all 21 new sites in `localization/english/bm_holy_sites_l_english.yml`.

- **Faith Tenets & Christian Branch**:
  - Base `quintessence_faith` updated with tenets: `tenet_sacred_shadows`, `tenet_communal_identity`, `tenet_ritual_celebrations`.
  - Created explicit `quintessence_faith_christian` (with `tenet_christian_syncretism`, `tenet_communal_identity`, `tenet_ritual_celebrations`), matching 1:1 mainline rite, heritage conversion routing in `bm_religion_conversion_effects.txt`, and localization.
  - Aligned tenets across other syncretic branches (`islamic`, `jewish`, `eastern`, `sinitic`, `asatru`, `unreformed`).

- **Reykjavík Blood Mage Duel Decision**:
  - Added decision `bm_challenge_reykjavik_blood_mage_decision` in `common/decisions/bm_reykjavik_blood_mage_duel_decision.txt`.
  - Governed by script values in `common/script_values/bm_reykjavik_duel_values.txt` and localized in `localization/english/bm_decisions_l_english.yml`.
  - Documented in `docs-ai/architecture/blood-mage-decisions.md` and `docs-ai/architecture/blood-mage-duels-and-education.md`.

- **CK3 Inspection Utility (`scripts/read_ck3.py`)**:
  - Reusable CLI tool and Python module to read CK3 files with UTF-8 BOM (`utf-8-sig`) handling, extract balanced `{ ... }` blocks (`block`), and search mod or vanilla reference files (`/Users/clarabotet/Petur/ck3-full`).
  - Documented with examples in `AGENTS.md` and referenced in `.agents/rules/ck3-scripting.md`.

## Key Decisions

- **Eminent sites are reserved for capitals and non-health bonus sites**: Sites giving general stat boosts (piety per knight, stats per piety level) or primary spiritual prestige (Rome, Constantinople, Jerusalem, Mecca, Olympus) are Eminent. All pure health, lifespan, and epidemic resistance sites are Regular holy sites.
- **`eminent_holy_sites_max` set to 25**: Allows all 16 Eminent sites to be active simultaneously without hitting engine capacity limits, while keeping regular sites well within `holy_sites_max = 80`.
- **Created a distinct `quintessence_faith_christian`**: Separated the generic base cult (`quintessence_faith`) from Christian syncretism, ensuring Christian converts route to an explicitly syncretic variant while the base faith maintains generic cult tenets (`sacred_shadows`, `communal_identity`, `ritual_celebrations`).
- **Added `scripts/read_ck3.py` for repository inspection**: Eliminates inline bash script parsing errors and character encoding corruption when reading files with UTF-8 BOM or mixed line endings.
