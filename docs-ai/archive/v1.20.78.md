# v1.20.78: Resolve Engine Errors, Trait Database Mismatches & Restore Blood Crucible

## Motivation

- Eliminate runtime database errors in `error.log`: The ascension duel mirror copying effect referenced invalid trait IDs (`harelip`, `lisp`, `blademaster_1..3`, `hunter_1..3`), generating 24 database validation failures on game startup.
- Restore intended modifier in Blood Blessing: `bm_blessed_blood_crucible_modifier` was fully defined, tuned, and localized for dynasty rites, but omitted from `bm_blood_blessing.txt` (which fell back to `lifeforce_modifier_mojo`), triggering engine warnings about unused modifiers.
- Fix decision debug logging data-localization failures: Decision `debug_log` statements used `[ROOT.Char.GetShortUINameNoTooltip] (ID:[ROOT.Char.GetID])`, but in decision script scope `ROOT` is already a Character. This caused `pdx_data_localize.cpp:161` runtime data errors and output blank actor names (`Actor:  (ID:)`) in `debug.log`.

## Changes

### Key changes

- **Ascension Duel Mirror Trait Database Alignment (`common/scripted_effects/bm_ascension_duel_effects.txt`)**:
  - Removed obsolete check for `harelip` (does not exist in CK3).
  - Corrected `lisp` to vanilla trait key `lisping`.
  - Replaced tiered IDs `blademaster_1/2/3` and `hunter_1/2/3` with tracked lifestyle traits `lifestyle_blademaster` and `lifestyle_hunter`.
- **Restore Blood Crucible in Blood Blessing (`common/character_interactions/bm_blood_blessing.txt`)**:
  - Added `has_character_modifier = bm_blessed_blood_crucible_modifier` to `NOR` eligibility triggers in `is_valid` and `starts_enabled` for `blessing_bless_bloodline`.
  - Replaced fallback `lifeforce_modifier_mojo` application in `blessing_bless_bloodline` with `bm_blessed_blood_crucible_modifier` for 10 years, matching the dynasty rite architecture.
- **Decision `debug_log` Data Localization Syntax (`common/decisions/`)**:
  - Standardized all 56 occurrences of `debug_log` across 14 decision files from `[ROOT.Char.GetShortUINameNoTooltip] (ID:[ROOT.Char.GetID])` to `[root.GetShortUINameNoTooltip] (ID:[root.GetID])`, eliminating all runtime `pdx_data_localize.cpp:161` errors.

### Other changes

- Added error signatures and remedies for `ROOT.Char` in decision scopes and CK3 vanilla trait database names to `.agents/rules/ck3-error-catalog.md`.
- Updated `RELEASE_NOTES.md` with v1.20.78 bugfix and version history entry.
