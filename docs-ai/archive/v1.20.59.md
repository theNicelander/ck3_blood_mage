# v1.20.59: Duchy Blood Temples, faith tenets and leaner agent docs

## Motivation

- Regular county buildings need vanilla `00_holdings.txt` edits, breaking the zero-overwrite rule and building-overhaul mods.
- Blood Temples were hidden instead of greyed out, and tribal rulers could not use them.
- Agent docs, rules and PR flow were verbose and duplicated, wasting tokens.

## Changes

- Blood Temples are 7-tier duchy-capital buildings (`bm_duchy_buildings.txt`), always visible, greyed out with failure tooltips until the ruler is a Blood Mage/Knight or Blóðtrú.
- Tribal rulers can build up to Tier IV; Tiers V–VII need a feudalized, non-tribal realm.
- Blood Berserkers cost more to recruit and maintain, with lower damage and pursuit.
- Blóðtrú faiths and rites swap Ritual Celebrations for Mendicant Preaching; Blood Mage/Knight traits are no longer faith virtues; the high god is "The Blood God".
- All Blóðtrú, Ketsudō, and Xuédào holy sites promoted to Eminent Holy Sites (`eminent_holy_sites_max = 80`), delivering smaller stacked global faith bonuses alongside county holder modifiers.
- Fixed missing `NOT_bm_can_drain_traits_from_target_trigger_tt` loc key.
- Agent workflow: `manage-pr` skill owns branch doc, PR, commit and push (PR-description style, `.github/pull_request_template.md`); `CHANGELOG.md` merged into a shorter `RELEASE_NOTES.md`; old branch docs archived to `docs-ai/archive/`; rules merged (decisions + AI) and error catalog split out; `AGENTS.md` and architecture docs condensed.
