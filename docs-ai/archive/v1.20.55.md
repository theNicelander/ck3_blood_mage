# v1.20.55: Blood Mage Track Restructuring (Part 1), Heal Old Age Trait Rework, Trait Variables, AI Lifedrain Protections, AI Spouse & Heir Initiation Priority, Ritual Sparring Decision, Education Devotion Scaling & Engine Fixes

## Summary & Motivation
Restructure the `bloodline` and `hematurgy` tracks in `lifestyle_blood_mage` to match the clean 10-step cadence of `lifestyle_blood_knight`, eliminating UI bloat by capping unique modifiers at 3–5 items and preventing CK3 decimal truncation bugs via whole-integer constraints. Rework old age degenerative traits (`infirm`, `clouded_eyes`, `fragile_bones`, `withering_mind`, `faltering_heart`) by separating them from instant-removal `bm_heal_ailment` into a dedicated progressive rejuvenation mechanic (`bm_heal_old_age_trait`), requiring multi-stage track XP reduction (-20 XP for Minor, -50 XP for Major) before allowing full cure (< 20 XP). Refactor fixed numerical modifier values across `lifestyle_blood_mage` and `lifestyle_blood_knight` trait tracks into reusable `@` script variables, standardize Blood Knight common stats, add a 1-year cooldown to Empower Dynasty Bloodline, protect spouses, children, knights, councillors, and court position holders from being lifedrained by AI blood mages, aggressively prioritise AI initiation of spouses and primary heirs as blood mages/knights, convert ritual sparring into an annual courtyard decision (`bm_ritual_spar_decision`), scale education enhancement devotion requirements and piety level costs across tiers (1★: Devotion 1+, 2★: Devotion 2+, 3★: Devotion 3+ with level cost, 4★: Devotion 4+ with level cost), and resolve all mod errors in `error.log`.

## Key Decisions
- **Tiered Devotion Progression for Education**: Scaled Devotion Level requirements to trait rank (1★ requires Devotion 1, 2★ requires Devotion 2, 3★ requires Devotion 3, 4★ requires Devotion 4), aligning with the mod's "Earned power over godmode" principle while removing the punitive devotion level loss from early 1★ and 2★ enhancements.
- **Selective Devotion Level Loss**: Confined `add_piety_level = -1` solely to elite milestones (3★ -> 4★ and 4★ -> 5★), giving players accessible early-game education refinement while keeping apex masteries consecrated and costly.
- **Progressive Old Age Track Management**: Replaced instant one-click removal of old age ailments with a tiered track XP reduction system (-20 XP for Minor, -50 XP for Major), reserving complete trait removal exclusively for tracks reduced below 20 XP. This reinforces the core mod philosophy of "Earned power over godmode".
- **Dynamic Unavailable Display**: Positioned Cure Ailment options with `show_as_unavailable = { scope:recipient = { has_trait = <trait> } }` so players can inspect the requirement tooltip ("Has less than 20 Trait Level Track XP") without cluttering the UI for characters unaffected by the affliction.
- **Prowess-Proportional Sampling Without Replacement**: Chose sequential `random_knight` calls with `weight = { base = 0 modifier = { add = prowess min = 1 } }` and exclusions (`NOT = { this = scope:spar_partner_X }`), mirroring vanilla while satisfying the exact mathematical requirement $P(i) = \text{prowess}_i / \sum \text{prowess}_k$.
- **Practice Fatality (`FATALITY = practice`)**: Guaranteed non-lethal, wound-free sparring where knights cannot be permanently crippled or killed in the ring.
- **Major Lifeforce Prize**: Elevated the sparring stakes so the victor condenses 1 Major Lifeforce stack from the intense combat expenditure, with both participants gaining Blademaster trait XP.
- **Standardized Cadence Alignment**: Aligned Blood Mage's `bloodline` and `hematurgy` tracks with Blood Knight's 10-step model to ensure consistent UI density and progression pacing across both classes.
- **Whole-Integer / Clean Multipliers**: Used whole percentages like `0.03` domain tax and `0.10` inactive inheritance to prevent decimal truncation and floating precision issues in CK3 UI formatting.
- **AI-Only Restriction**: Enforced through `scope:actor = { is_ai = yes }` blocks in interaction validity and AI weights, leaving player agency unrestricted.
- **Total Ban on Spouses & Kids**: Blocked unconditionally even in prison or as rivals/nemeses for AI characters.
- **Factor = 0 Ordering**: Positioned all vetoes at the very end of `ai_will_do` calculations in accordance with Clausewitz engine evaluation rules.
- **Self-Contained File Variables**: Defined variables at the top of both trait files independently so that each trait definition remains modular, self-contained, and easily readable without cross-file script value lookups.
- **1-Year Decision-Level Cooldown**: Standardized to native CK3 decision `cooldown = { years = 1 }`, ensuring clear UI cooldown display without requiring custom flag tracking.
